## CRUD

**CRUD** — это аббревиатура от 4 основных операций, которые выполняются с данными в большинстве приложений:

- **C**reate — создать (добавить новую запись)
- **R**ead — прочитать (загрузить и отобразить данные)
- **U**pdate — обновить (изменить существующую запись)
- **D**elete — удалить (убрать запись из данных)

Эти операции лежат в основе почти всех программ: от заметок и задач до интернет-магазинов и социальных сетей.

Давайте реализуем методы CRUD для JSON файла.

```python
import json
import os


def load_json(folder_name, file_name):
    if not os.path.exists(folder_name):
        os.mkdir(folder_name)
    full_path = os.path.join(folder_name, file_name)
    if not os.path.exists(full_path):
        with open(full_path, "w", encoding="utf-8") as f:
            json.dump([], f, ensure_ascii=False, indent=2)
    with open(full_path, "r", encoding="utf-8") as f:
        return json.load(f)


def save_json(folder_name, file_name, data):
    if not os.path.exists(folder_name):
        os.mkdir(folder_name)
    full_path = os.path.join(folder_name, file_name)
    with open(full_path, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
```

**JSON (JavaScript Object Notation)** — это удобный и понятный формат для хранения структурированных данных. Он похож на словари и списки в Python, поэтому с ним легко работать.

#### Create

```python
def create_book(book):
    book_lst = load_json(folder_name, file_name)
    idx = len(book_lst) + 1
    book.update({"id": idx})
    book_lst.append(book)
    save_json(folder_name, file_name, book_lst)
```

Программист не знает, под каким номером будет записана его книга, это программисту не важно. Функция сама придумает под каким id записать книгу в свою базу данных. При работе с реальной БД, за присвоением номера следит она сама, а тут приходится нам каждый раз расчитывать, какой id будет у новой записи.

#### Read

```python
def get_books():
    book_lst = load_json(folder_name, file_name)
    return book_lst
```

Здесь мы получаем полный список книг. Это работает, пока книг мало. Когда наше хранилище разрастётся, тогда мы не сможем загрузить весь объём в память.

Чтобы этого избежать используются фильтры, пагинация и запрос одной записи, зная её id.

```python
def get_book(idx):
    book_lst = load_json(folder_name, file_name)
    for book in book_lst:
        if book["id"] == idx:
            return book
    return {}
```

#### Update

```python
def update_book(idx, new_book):
    book_lst = load_json(folder_name, file_name)
    for book in book_lst:
        if book["id"] == idx:
            book.update(new_book)
    save_json(folder_name, file_name, book_lst)
```

Здесь мы итерируемся по списку книг и если нашли книгу с нужным id, то обновляем её.

Обратите внимание, что функция не проверяет на наличие книги с таким id. Функция обновляет все поля записи в хранилище данных. Программист не знает произошло ли обновление и что именно обновилось. Можно дорабатывать эту часть программы. Например написать ещё одну программу `create_or_update()`

#### Delete

```python
def delete_book(idx):
    book_lst = load_json(folder_name, file_name)
    i = 0
    f = None
    for book in book_lst:
        if book["id"] == idx:
            f = i
            break
        i += 1
    if f is not None:
        book_lst.pop(i)
    else:
        print(f"Не найдена запись {idx}")
    save_json(folder_name, file_name, book_lst)
```

Здесь мы ищем совпадение id и если такая запись найдена, мы запоминаем номер элемента в списке, а затем удаляем его. Обратите внимание, что удаление происходит после того, как закончился цикл. Итерируемый объект не должен изменяться во время итерации по нему.

Программа пишет в консоль сообщение о том, что запись не удалось удалить. В реальной жизни это сообщение никто не увидит. Можно возвращать в качестве ответа сообщение, удалось ли удалить запись и какую именно.
