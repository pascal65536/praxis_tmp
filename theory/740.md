# Передача файлов на сервер с помощью Flask

Flask предоставляет удобный способ для обработки загрузки файлов от пользователей. Пример кода:

{% raw %}
```python
from flask import Flask, render_template, request

app = Flask(__name__)

# Путь для сохранения загруженных файлов
UPLOAD_FOLDER = 'uploads'
app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER

@app.route('/', methods=['GET', 'POST'])
def upload_file():
    if request.method == 'POST':
        if 'file' not in request.files:
            return 'No file part'
        file = request.files['file']

        # Проверка, был ли выбран файл
        if file.filename == '':
            return 'No selected file'

        # Сохранение файла
        file.save(f"{app.config['UPLOAD_FOLDER']}/{file.filename}")
        return 'File successfully uploaded'
    return render_template('upload.html')

if __name__ == '__main__':
    app.run(debug=True)
```
{% endraw %}

**Обработка запросов POST:**

- Проверка, был ли передан файл (`'file' not in request.files`)
- Получение файла из запроса (`file = request.files['file']`)
- Проверка, был ли выбран файл (`file.filename == ''`)
- Сохранение файла с помощью метода `save()` в указанную директорию.

**upload.html:**

{% raw %}
```html
<!DOCTYPE html>
<html>
<head>
    <title>Загрузка файла</title>
</head>
<body>
    <h1>Загрузите файл</h1>
    <form method="POST" enctype="multipart/form-data">
        <input type="file" name="file">
        <input type="submit" value="Загрузить">
    </form>
</body>
</html>
```
{% endraw %}

**Обратите внимание:**

- `enctype="multipart/form-data"`: Необходимо указать этот атрибут в форме HTML для корректной передачи файлов.
- Перед сохранением файла рекомендуется проверять его тип, размер и другие параметры, чтобы предотвратить загрузку вредоносных файлов.
- Убедитесь, что директория `uploads` существует в той же папке, где находится ваш файл `app.py`.

## Добавим модуль os и его магию.

{% raw %}
```python
from flask import Flask, render_template, request
import os

app = Flask(__name__)

root = os.path.dirname(os.path.realpath(__file__))
UPLOAD_FOLDER = os.path.join(root, 'uploads')
if not os.path.exists(UPLOAD_FOLDER):
    os.makedirs(UPLOAD_FOLDER)
app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER


@app.route('/', methods=['GET', 'POST'])
def upload_file():
    if request.method == 'POST':
        if 'file' not in request.files:
            return 'No file part'

        file = request.files['file']
        if file.filename == '':
            return 'No selected file'

        file_save_path = os.path.join(app.config['UPLOAD_FOLDER'], file.filename)
        file.save(file_save_path)
        return 'File successfully uploaded'

    return render_template('upload.html')

if __name__ == '__main__':
    app.run(debug=True)
```
{% endraw %}

# Определение типа файла в Python

В Python существует несколько способов определить тип файла:

## 1. Использование модуля os.path:

Этот метод наиболее распространен и прост в использовании. Он позволяет получить расширение файла и на основе него сделать вывод о типе файла.

{% raw %}
```python
import os

def get_file_type(file_path):
  """Определяет тип файла по расширению."""
  _, file_extension = os.path.splitext(file_path)
  if file_extension == ".txt":
    return "Текстовый файл"
  elif file_extension == ".jpg" or file_extension == ".jpeg" or file_extension == ".png":
    return "Изображение"
  elif file_extension == ".pdf":
    return "PDF документ"
  else:
    return "Неизвестный тип файла"

file_path = "my_file.txt"
file_type = get_file_type(file_path)
print(f"Тип файла: {file_type}")
```
{% endraw %}

## 2. Использование библиотеки mimetypes:

Эта библиотека предоставляет более точный способ определения типа файла, основываясь на его содержимом, а не только на расширении.

{% raw %}
```python
import mimetypes

def get_file_type(file_path):
  """Определяет тип файла с помощью mimetypes."""
  mime_type, _ = mimetypes.guess_type(file_path)
  if mime_type:
    return mime_type
  else:
    return "Неизвестный тип файла"

file_path = "my_image.jpg"
file_type = get_file_type(file_path)
print(f"Тип файла: {file_type}")
```
{% endraw %}

## 3. Использование внешних библиотек (например, magic):

Для более сложных задач, требующих более точного определения типа файла, можно использовать внешние библиотеки, такие как `python-magic`. Эта библиотека предоставляет доступ к библиотеке `libmagic`, которая способна определять тип файла на основе его содержимого.

{% raw %}
```python
import magic

def get_file_type(file_path):
  """Определяет тип файла с помощью python-magic."""
  mime = magic.Magic(mime=True)
  file_type = mime.from_file(file_path)
  return file_type

file_path = "my_document.docx"
file_type = get_file_type(file_path)
print(f"Тип файла: {file_type}")
```
{% endraw %}

**Важно:**

- **Надежность**: Определение типа файла по расширению может быть ненадежным, так как пользователь может переименовать файл, не меняя его содержимое.
- **Точность**: Библиотека `mimetypes` и `python-magic` предоставляют более точный результат, но могут быть более ресурсоемкими.
- **Выбор метода**: Выбор метода зависит от конкретной задачи и требований к точности.
