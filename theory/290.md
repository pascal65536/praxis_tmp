# Форматированные строки

В Python, начиная с версии 3.6 работает способ форматирования строк, называемый f-string (formatted string literals). Возможности форматирования строк огромны.

В теле строки могут находиться включения в фигурных скобках. В процессе выполнения программы интерпретатор исполняет выражения в фигурных скобках, вставляя их результат в соответстующие места строки.

Например, предположим, что вы хотите отобразить результат арифметического вычисления. Это можно сделать с помощью простого `print()` и оператора `,`, разделяющего числовые значения и строковые:


```python
n = 20
m = 25
prod = n * m
print('Произведение', n, 'на', m, 'равно', prod)  # Вывод: Произведение 20 на 25 равно 500
```


Но это громоздко. Чтобы выполнить то же самое с помощью f-string :

- Напишите `f` перед кавычками строки. Это укажет Python, что это f-string а не стандартная.
- Укажите любые переменные для воспроизведения в фигурных скобках (`{}`).

Код с использованием f-string, приведенный ниже выглядит намного чище:


```python
n = 20
m = 25
prod = n * m
print(f'Произведение {n} на {m} равно {prod}')  # Вывод: Произведение 20 на 25 равно 500
```


Кавычки могут быть любые:


```python
var = 'Пример'
print(f'Одинарные кавычки {var}!')  # Вывод: Одинарные кавычки Пример!
print(f"Двойные кавычки {var}!")  # Вывод: Двойные кавычки Пример!
print(f'''Тройные кавычки {var}!''')  # Вывод: Тройные кавычки Пример!
```


Внутри f-string могут быть переменные любого типа:


```python
user = input()
print(f'Hello {user}!')  # Вывод: Hello Сергей!

num = 65536
print(f'Count {num}')  # Вывод: Count 65536    

pi = 3.1415926
print(f'Result {pi}')  # Вывод: Result 3.1415926
```


Вместо переменной внутри f-string может быть и выражение:


```python
print(f'Division {22/7}')  # Вывод: Division 3.142857142857143
```


## Форматирование вещественных чисел


```python
pi = 3.1415926
print(f'Result {pi:.2f}')  # Вывод: Result 3.14
print(f'Result {pi:.4f}')  # Вывод: Result 3.1416

print(f'Result {pi:5.2f}')  # Вывод: Result  3.14
print(f'Result {pi:5.3f}')  # Вывод: Result 3.142
print(f'Result {pi:5.4f}')  # Вывод: Result 3.1416

print(f'Result {pi:10.2f}')  # Вывод: Result       3.14
print(f'Result {pi:10.3f}')  # Вывод: Result      3.142
print(f'Result {pi:10.4f}')  # Вывод: Result     3.1416
```


## Форматирование разделителей целых чисел


```python
num = -1234567890
print(f"Число с разделителем: {num:,}")  # Вывод: Число с разделителем: -1,234,567,890
print(f"Число с разделителем: {num:_}")  # Вывод: Число с разделителем: -1_234_567_890

num = 1_200_400_001
print(num)  # Вывод: 1200400001
print(f'{num:_}')  # Вывод: 1_200_400_001
print(f'{num:,}')  # Вывод: 1,200,400,001
```


## Форматирование строк


```python
text = "Python"
print(f"|{text:<10}|")  # Вывод: |Python    |
print(f"|{text:>10}|")  # Вывод: |    Python|
print(f"|{text:^10}|")  # Вывод: |  Python  |

y = 300
print(f'{y:.>15}')  # Вывод: ............300
print(f'{y:.<15}')  # Вывод: 300............
print(f'{y:.^15}')  # Вывод: ......300......
```


## Форматирование процентов


```python
val = 1/7.0
print(f'{val}')  # Вывод: 0.14285714285714285
print(f'{val:.2%}')  # Вывод: 14.29%
```


## Форматирование ширины строк


```python
x = 1
print(f'{x:02} {x*x:3} {x*x*x:4}')  # Вывод: 01   1    1
x = 5  
print(f'{x:02} {x*x:3} {x*x*x:4}')  # Вывод: 05  25  125
x = 10
print(f'{x:02} {x*x:3} {x*x*x:4}')  # Вывод: 10 100 1000
x = 15
print(f'{x:02} {x*x:3} {x*x*x:4}')  # Вывод: 15 225 3375
```


## Заполнение незначащими нулями


```python
y = 1
print(f'{y:05}')  # Вывод: 00001
y = 20
print(f'{y:05}')  # Вывод: 00020
y = 300
print(f'{y:05}')  # Вывод: 00300
```


## Форматирование представления чисел


```python
val = 300

# hexadecimal lower
print(f'{val:x}')   # Вывод: 12c

# hexadecimal upper
print(f'{val:X}')   # Вывод: 12C

# octal
print(f'{val:o}')   # Вывод: 374

# binary
print(f'{val:b}')   # Вывод: 1100100

# scientific
print(f'{val:e}')   # Вывод: 3.000000e+02
```


## Форматирование методами строк


```python
a = "Hello"
print('|', a.center(10), '|')   # Вывод: |   Hello    |
print(a.rjust(14))              # Вывод:          Hello
print(a.ljust(10))              # Вывод: Hello
print(a.ljust(14, '.'))         # Вывод: Hello.........
print(a.center(14, '.'))        # Вывод: ....Hello.....
```
