## Инкапсуляция

**Определение:** Инкапсуляция — это один из ключевых принципов ООП, который позволяет скрывать внутренние детали реализации класса и предоставлять доступ к данным только через методы. Это помогает защитить данные от неправильного использования и делает код более безопасным и удобным для работы.

### Основные идеи инкапсуляции:

1. **Сокрытие данных**: атрибуты класса делаются приватными (недоступными извне).
2. **Доступ через методы**: для работы с приватными атрибутами используются специальные методы (геттеры и сеттеры).

### Пример инкапсуляции:

Создадим класс `BankAccount`, который представляет банковский счет. Мы сделаем атрибут `__balance` (баланс) приватным, чтобы его нельзя было изменить напрямую. Для работы с балансом будем использовать методы.

```
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner  # Владелец счета (публичный атрибут)
        self.__balance = balance  # Баланс счета (приватный атрибут)

    # Метод для пополнения счета
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            print(f"Счет пополнен на {amount}. Новый баланс: {self.__balance}")
        else:
            print("Сумма для пополнения должна быть положительной.")

    # Метод для снятия средств
    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            print(f"Со счета снято {amount}. Новый баланс: {self.__balance}")
        else:
            print("Недостаточно средств или неверная сумма для снятия.")

    # Геттер для получения баланса
    def get_balance(self):
        return self.__balance

    # Сеттер для установки баланса (с проверкой)
    def set_balance(self, balance):
        if balance >= 0:
            self.__balance = balance
        else:
            print("Баланс не может быть отрицательным.")

# Создаем объект BankAccount
account = BankAccount("Иван Иванов", 1000)

# Пополняем счет
account.deposit(500)  # Счет пополнен на 500. Новый баланс: 1500

# Снимаем средства
account.withdraw(200)  # Со счета снято 200. Новый баланс: 1300

# Пытаемся снять слишком много
account.withdraw(2000)  # Недостаточно средств или неверная сумма для снятия.

# Получаем баланс через геттер
print(f"Текущий баланс: {account.get_balance()}")  # Текущий баланс: 1300

# Пытаемся изменить баланс напрямую (не получится)
account.__balance = 5000  # Ничего не произойдет, баланс останется прежним
print(f"Баланс после попытки прямого изменения: {account.get_balance()}")  # Баланс: 1300

# Устанавливаем баланс через сеттер
account.set_balance(2000)  # Баланс изменен
print(f"Новый баланс: {account.get_balance()}")  # Новый баланс: 2000

# Пытаемся установить отрицательный баланс
account.set_balance(-100)  # Баланс не может быть отрицательным.
```

### Что тут происходит:

1. **Приватный атрибут**: `__balance` — это приватный атрибут. Его нельзя изменить напрямую извне класса.
2. **Методы для работы с балансом**:

- `deposit` — пополняет счет.
- `withdraw` — снимает средства.
- `get_balance` — возвращает текущий баланс.
- `set_balance` — устанавливает баланс (с проверкой на корректность).

1. **Защита данных**: мы контролируем, как изменяется баланс, и предотвращаем некорректные операции (например, отрицательный баланс).

### Преимущества инкапсуляции:

- **Безопасность**: данные защищены от неправильного использования.
- **Гибкость**: можно изменить внутреннюю реализацию класса, не затрагивая код, который его использует.
- **Контроль**: можно добавить проверки и логику при изменении данных.
