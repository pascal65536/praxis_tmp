## Функции высших порядков

Функции высших порядков — это функции, которые могут принимать другие функции в качестве аргументов или возвращать их в качестве результата. Это позволяет создавать более гибкий и модульный код.

### Примеры функций высших порядков в Python:

#### 1. filter():

Функция `filter()` используется для фильтрации элементов из итерируемого объекта на основе заданного условия.

**Пример**: выбрать только положительные числа из списка:

```python
def only_pos(x):
    return x > 0
     
result = filter(only_pos, [-1, 5, 6, -10, 0])
print(", ".join(str(x) for x in result))  # Вывод: 5, 6
```

#### 2. map():

Функция `map()` применяет заданную функцию к каждому элементу итерируемого объекта и возвращает итератор с результатами.

**Пример**: возвести в квадрат числа из списка:

```python
def square(x):
    return x ** 2

result = map(square, range(5))
print(", ".join(str(x) for x in result))  # Вывод: 0, 1, 4, 9, 16
```

#### 3. sorted():

Функция `sorted()` сортирует элементы итерируемого объекта. Она может принимать функцию в аргументе `key`, которая определяет критерий сортировки.

**Пример**: сортировка списка строк по длине:

```python
lines = ["abcd", "ab", "abc", "abcdef"]
print(sorted(lines, key=lambda line: len(line)))  # Вывод: ['ab', 'abc', 'abcd', 'abcdef']
```

### Лямбда-функции

**Лямбда-функции** — это анонимные функции, которые могут быть определены в одной строке. Они часто используются в функциях высших порядков для краткости и удобства.

**Синтаксис лямбда-функции:**

```python
lambda аргументы: выражение
```

**Примеры использования лямбда-функций:**

**1. В функции `filter()`:**

```python
result = filter(lambda x: x > 0, [-1, 5, 6, -10, 0])
print(", ".join(str(x) for x in result))  # Вывод: 5, 6
```

**2. В функции `map()`:**

```python
result = map(lambda x: x  2, range(5))
print(", ".join(str(x) for x in result))  # Вывод: 0, 1, 4, 9, 16
```

**3. В функции `sorted()`:**

Сортировка по длине строки:

```python
lines = ["abcd", "ab", "ba", "acde"]
print(sorted(lines, key=lambda line: len(line)))  # Вывод: ['ab', 'ba', 'abcd', 'acde']
```

Сортировка по нескольким критериям (длина и алфавит):

```python
print(sorted(lines, key=lambda line: (len(line), line)))  # Вывод: ['ab', 'ba', 'abcd', 'acde']
```

Сортировка по убыванию длины:

```python
print(sorted(lines, key=lambda line: (-len(line), line)))  # Вывод: ['abcd', 'acde', 'ab', 'ba']
```

**4. В функции `reduce()`:**

Суммирование элементов списка:

```python
from functools import reduce
numbers = range(1, 6)
print(reduce(lambda x, y: x + y, numbers))  # Вывод: 15
```

#### Добавим

**Именованные аргументы:** В Python можно передавать аргументы в функцию по имени, что делает код более читаемым и позволяет задавать значения по умолчанию.

```python
def final_price(price, discount=1):
    return price - price * discount / 100
 
print(final_price(1000, discount=5))  # Вывод: 950.0
print(final_price(discount=10, price=1000))  # Вывод: 900.0
```

**Передача неограниченного количества аргументов:**

Позиционные аргументы с использованием `*args`:

```python
def final_price(*prices, discount=1):
    return [price - price * discount / 100 for price in prices]
   
    print(final_price(100, 200, 300, discount=5))  # Вывод: [95.0, 190.0, 285.0]
```

Именованные аргументы с использованием `kwargs`:

```python
def final_price(*prices, discount=1, kwargs):
    low = kwargs.get("price_low", min(prices))
    high = kwargs.get("price_high", max(prices))
    return [price - price * discount / 100 for price in prices if low <= price <= high]
    
print(final_price(100, 200, 300, 400, 500, discount=5))  # Вывод: [95.0, 190.0, 285.0, 380.0, 475.0]
```
