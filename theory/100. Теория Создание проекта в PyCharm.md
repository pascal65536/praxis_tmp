## Создание проекта в PyCharm

1. Нужно создать проект. Для этого я создаю папку и называю её латинскими символами без пробелов, например "my_project"
2. В папку помещаю файл, который надо открыть
3. С помощью редактора кода PyCharm или VSC открываю папку, а не файл. Папку, именно папку!
4. В PyCharm видно, что открыт проект - в левом верхнем углу появилась папка и внутри файл
5. В PyCharm Создаю программу так: ПКМ по папке -> New -> Python file
