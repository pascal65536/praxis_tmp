## Логирование

Добавим **логирование** операций в класс `BankAccount`. Логирование поможет отслеживать все действия со счетом: пополнение, снятие средств и изменение баланса. Для этого будем использовать модуль `logging` из стандартной библиотеки Python.
### Пример с логированием:

```python
import logging

# Настройка логирования
logging.basicConfig(
    level=logging.INFO,  # Уровень логирования (INFO, WARNING, ERROR и т.д.)
    format="%(asctime)s - %(levelname)s - %(message)s",  # Формат сообщений
    filename="bank_account.log",  # Логи будут записываться в файл
)

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner  # Владелец счета
        self.__balance = balance  # Приватный атрибут: баланс
        logging.info(f"Создан новый счет для {self.owner}. Начальный баланс: {self.__balance}")

    # Метод для пополнения счета
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            logging.info(f"Счет {self.owner} пополнен на {amount}. Новый баланс: {self.__balance}")
            print(f"Счет пополнен на {amount}. Новый баланс: {self.__balance}")
        else:
            logging.warning(f"Попытка пополнения счета {self.owner} на недопустимую сумму: {amount}")
            print("Сумма для пополнения должна быть положительной.")

    # Метод для снятия средств
    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            logging.info(f"Со счета {self.owner} снято {amount}. Новый баланс: {self.__balance}")
            print(f"Со счета снято {amount}. Новый баланс: {self.__balance}")
        else:
            logging.warning(f"Попытка снятия со счета {self.owner} недопустимой суммы: {amount}")
            print("Недостаточно средств или неверная сумма для снятия.")

    # Геттер для получения баланса
    def get_balance(self):
        logging.info(f"Запрос баланса для {self.owner}. Текущий баланс: {self.__balance}")
        return self.__balance

    # Сеттер для установки баланса (с проверкой)
    def set_balance(self, balance):
        if balance >= 0:
            self.__balance = balance
            logging.info(f"Баланс счета {self.owner} изменен на {balance}.")
            print(f"Баланс изменен на {balance}.")
        else:
            logging.error(f"Попытка установки отрицательного баланса для {self.owner}: {balance}")
            print("Баланс не может быть отрицательным.")

# Создаем объект BankAccount
account = BankAccount("Иван Иванов", 1000)

# Пополняем счет
account.deposit(500)  # Счет пополнен на 500. Новый баланс: 1500

# Снимаем средства
account.withdraw(200)  # Со счета снято 200. Новый баланс: 1300

# Пытаемся снять слишком много
account.withdraw(2000)  # Недостаточно средств или неверная сумма для снятия.

# Получаем баланс через геттер
print(f"Текущий баланс: {account.get_balance()}")  # Текущий баланс: 1300

# Устанавливаем баланс через сеттер
account.set_balance(2000)  # Баланс изменен на 2000.

# Пытаемся установить отрицательный баланс
account.set_balance(-100)  # Баланс не может быть отрицательным.
```

### Что изменилось:

1. **Логирование**:

- Используется модуль `logging` для записи событий в файл `bank_account.log`.
- Логируются все ключевые действия: создание счета, пополнение, снятие, запрос баланса и изменение баланса.
- Для разных ситуаций используются разные уровни логирования:

1. `INFO` — для обычных событий (например, пополнение счета).
2. `WARNING` — для подозрительных действий (например, попытка снять слишком много).
3. `ERROR` — для ошибок (например, попытка установить отрицательный баланс).
4. **Файл логов**:

- Все логи записываются в файл `bank_account.log`.
- Пример содержимого файла:

```text
2025-03-10 12:00:00,000 - INFO - Создан новый счет для Иван Иванов. Начальный баланс: 1000
2025-03-10 12:00:01,000 - INFO - Счет Иван Иванов пополнен на 500. Новый баланс: 1500
2025-03-10 12:00:02,000 - INFO - Со счета Иван Иванов снято 200. Новый баланс: 1300
2025-03-10 12:00:03,000 - WARNING - Попытка снятия со счета Иван Иванов недопустимой суммы: 2000
2025-03-10 12:00:04,000 - INFO - Запрос баланса для Иван Иванов. Текущий баланс: 1300
2025-03-10 12:00:05,000 - INFO - Баланс счета Иван Иванов изменен на 2000.
2025-03-10 12:00:06,000 - ERROR - Попытка установки отрицательного баланса для Иван Иванов: -100
```

### Преимущества логирования:

- **Отслеживание операций**: можно понять, что происходило со счетом в любой момент.
- **Диагностика проблем**: если что-то пошло не так, логи помогут найти причину.
- **Безопасность**: подозрительные действия (например, попытка снять слишком много) фиксируются.
