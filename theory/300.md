# Функции

Функции в Python - это блоки кода, которые могут быть вызваны для выполнения определенной задачи. Функции позволяют организовать код в более логическую и удобную структуру, а также повторно использовать код.

## В математике:

Функция – это зависимость одной переменной величины от другой. Другими словами, взаимосвязь между величинами.

Функция – это определенное действие над переменной.

## В программировании:

Функция или подпрограмма — фрагмент программного кода, к которому можно обратиться из другого места программы. В большинстве случаев с функцией связывается идентификатор. При вызове происходит выполнение команд тела функции. После выполнения функции управление возвращается обратно в адрес возврата — точку программы, где данная функция была вызвана.

## Определение функций:

Для определения функции в Python используется ключевое слово `def`, за которым следует имя функции и круглые скобки. Внутри скобок могут быть указаны аргументы функции, если они необходимы. Затем после двоеточия следует блок кода, который будет выполняться при вызове функции.


```python
def say_hello():
    print("Привет, мир!")
```


## Вызов функций:

Для вызова функции используется ее имя, за которым следуют круглые скобки. Если функция принимает аргументы, они должны быть переданы в круглых скобках.


```python
say_hello()  # Вывод Привет, мир!
```


Функции работающие без аргументов, чаще всего применяются для инициализации переменных, для задания стартовых значений и т.п.

## Возвращение значений:

Функции могут возвращать значения с помощью ключевого слова `return`. То, что вернула функция будет использовано в другой части программы.


```python
def add_numbers(a, b):
    return a + b

result = add_numbers(5, 3)
print(result)  # Выведет 8
```


Создадим функцию, которая открывает текстовый файл *data.txt* и возвращает список целых чисел, хранящихся в нём.


```python
def get_data():
    with open('data.txt') as f:
        data_lst = f.readlines()
    result = list()
    for data in data_lst:
        if not data:
            continue
        result.append(int(data.strip()))
    return result
```


## Аргументы функций:

Для расширения возможностей функции, в неё передают аргументы, которые используются внутри функции. Аргументы указываются в круглых скобках при определении функции.


```python
def greet(name):
    print(f"Привет, {name}!")
```


Модернизируем функцию, открывающую файл *data.txt*, пусть теперь функция умеет открывать любой файл.


```python
def get_data(filename):
    with open(filename) as f:
        data_lst = f.readlines()
    result = list()
    for data in data_lst:
        if not data:
            continue
        result.append(int(data.strip()))
    return result
```


## Значения аргументов по умолчанию:

Аргументы функции могут иметь значения по умолчанию. Если аргумент не передан при вызове функции, будет использовано значение по умолчанию.


```python
def calculator(op1, op2, operator='*'):
    if operator == '+':
        result = op1 + op2
    elif operator == '-':
        result = op1 - op2
    elif operator == '/':
        result = op1 / op2
    else:
        result = op1 * op2
    return result

print(calculator(10, 12))       #  Вывод 120
print(calculator(12, 15, '*'))  #  Вывод 180
print(calculator(15, 19, '+'))  #  Вывод 34
print(calculator(29, 20, '-'))  #  Вывод 9
```




### Именованные аргументы

В Python можно передавать аргументы в функцию по имени, что делает код более читаемым и позволяет задавать значения по умолчанию.


```python
def final_price(price, discount=1):
    return price - price * discount / 100
 
print(final_price(1000, discount=5))  # Вывод: 950.0
print(final_price(discount=10, price=1000))  # Вывод: 900.0
```


### Передача неограниченного количества аргументов

Позиционные аргументы с использованием `*args`:


```python
def final_price(*prices, discount=1):
    return [price - price * discount / 100 for price in prices]
   
    print(final_price(100, 200, 300, discount=5))  # Вывод: [95.0, 190.0, 285.0]
```


### Именованные аргументы с использованием `kwargs`


```python
def final_price(*prices, discount=1, kwargs):
    low = kwargs.get("price_low", min(prices))
    high = kwargs.get("price_high", max(prices))
    return [price - price * discount / 100 for price in prices if low <= price <= high]
    
print(final_price(100, 200, 300, 400, 500, discount=5))  # Вывод: [95.0, 190.0, 285.0, 380.0, 475.0]
```



## Локальные и глобальные переменные:

**Глобальные** переменные, как правило, определяются вначале программы и их имена записываются ЗАГЛАВНЫМИ буквами. Такие переменные называются константами. Обычно это адреса, папки, цвета с которыми работает программа. Имя состоящее целиком из заглавных букв -- сигнал программисту, что такую переменную иземенять нельзя. Язык это позволяет, но программисты так договорились и не меняют их.


```python
PI = 3.1415926

def square_circle(r):
    return PI * r * r

print(square_circle(3))  # Вывод 28.274333400000003
```


[Изображение: кольцо с внутренним радиусом r и внешним радиусом R]

Найти площадь кольца. Внутренний радиус r, внешний радиус R.


```python
PI = 3.1415926

def square_circle(r):
    result = PI * r ** 2
    return result

R = 10
r = 1

print(square_circle(R) - square_circle(r))  # Вывод 311.0176674
print(result)  # Вывод NameError: name 'result' is not defined
```


Программа падает на последней строке, потому что переменная `result` неопределена. Она известна программе только тогда, когда выполняется функция `square_circle()`. Такие переменные называются **локальными**.

Переменные, объявленные внутри функции, являются локальными и доступны только внутри этой функции. Переменные, объявленные за пределами функции, являются глобальными и доступны в любой части программы.

## Когда пора писать функцию?

1. Когда программист видит, в программе несколько одинаковых строк кода. DRY -- не повторяй себя. Если код повторяется, то его следует вынести в отдельный блок. Тогда одно изменение отразится на все вызовы функции, иначе придётся искать в коде одинаковые части. Это часто приводит к ошибкам.

2. Когда программист чётко разделяет блоки кода. Например -- блок ввода, блок обработки, блок вывода. В таком случае каждый блок следует выделить в отдельную функцию.

3. Когда программа стала слишком длинной. За длинным текстом программы сложно уследить. Тогда следует вынести один из логических блоков в функцию.

4. Когда функция разрослась. Часто бывает так, что функция разрастается, тогда эту функцию следует тоже разбить на функции. Да, функция может вызывать функцию.
