# Рекурсия

Рекурсия - это процесс, при котором функция вызывает саму себя. Рекурсивные функции могут использоваться для решения задач, которые могут быть разбиты на более простые подзадачи. В этом уроке мы рассмотрим основы рекурсии и как ее применять в функциях в Python.

**Основы рекурсии:**

Рекурсивная функция обычно имеет два случая: базовый случай и рекурсивный случай. В базовом случае функция возвращает результат без дополнительных рекурсивных вызовов. В рекурсивном случае функция вызывает саму себя с аргументами,

{% raw %}
```python
def countdown(n):
    if n <= 0:  # Базовый случай
        print("Готово!")
    else:  # Рекурсивный случай
        print(n)
        countdown(n-1)

countdown(5)

'''
5
4
3
2
1
Готово!
'''
```
{% endraw %}

**Примеры рекурсивных функций:**

Рекурсивные функции могут использоваться для решения различных задач. Например, рассмотрим рекурсивную функцию для вычисления факториала числа.

{% raw %}
```python
def factorial(n):
    if n == 0:  # Базовый случай
        return 1
    else:  # Рекурсивный случай
        return n * factorial(n-1)

result = factorial(5)
print(result)  # Выведет 120
```
{% endraw %}

**Ограничения рекурсии:**

Рекурсия может быть очень мощным инструментом, но она имеет свои ограничения. Одно из них - это глубина рекурсии, то есть количество рекурсивных вызовов, которые можно сделать до достижения максимальной глубины стека вызовов. Если глубина рекурсии слишком велика, может произойти переполнение стека вызовов.

**Оптимизация рекурсии:**

В некоторых случаях рекурсивные функции могут быть неэффективными из-за повторных вычислений. Для оптимизации рекурсии можно использовать мемоизацию, то есть сохранять результаты вычислений и использовать их при повторных вызовах функции.

{% raw %}
```python
memo = {}

def fibonacci(n):
    if n in memo:  # Проверяем, есть ли результат в мемоизации
        return memo[n]
    elif n <= 1:  # Базовые случаи
        return n
    else:  # Рекурсивный случай
        result = fibonacci(n-1) + fibonacci(n-2)
        memo[n] = result  # Сохраняем результат в мемоизации
        return result

result = fibonacci(10)
print(result)  # Выведет 55
```
{% endraw %}

# Рекурсия (суш.) — см. рекурсия

## Как устроена рекурсия

- **Рекурсивный вызов**: функция запускает копию самой себя с новыми, обычно более простыми или меньшими входными данными.
- **Базовое условие (базовый случай)**: правило остановки, при котором функция больше не вызывает себя, что позволяет предотвратить бесконечный цикл и переполнение памяти.

## Классический пример (факториал)

На Python вычисление факториала числа n выглядит так:

{% raw %}
```python
def factorial(n):
  if n == 1:  # Базовый случай
    return 1
  return n * factorial(n - 1)  # Рекурсивный вызов
```
{% endraw %}

Чтобы посчитать факториал числа n, надо n умножить на факториал числа n - 1.

## Кролики и числа Фибоначчи

Сформулируем знаменитую задачу о размножении кроликов: _«Некто поместил пару кроликов в загоне, огороженном со всех сторон, дабы узнать, сколько пар кроликов родится в течение года. Природа кроликов такова, что через месяц пара кроликов производит на свет другую пару, а потомство дают они со второго месяца после своего рождения»_.

{% raw %}
```python
def f(n):
    if n in [0, 1]:  # Базовый случай
        return 1
    return f(n - 1) + f(n - 2)  # Рекурсивный вызов
```
{% endraw %}

## Кэшируй это!

{% raw %}
```python
cache = dict()
cache = {0: 1, 1: 1}


def f(n):
    if n not in cache:
        cache[n] = f(n - 1) + f(n - 2)
    return cache[n]
```

## Декорируй это!

{% raw %}
```python
from functools import lru_cache


@lru_cache(maxsize=None)
def f(n):
    if n in [0, 1]:  # Базовый случай
        return 1
    return f(n - 1) + f(n - 2)  # Рекурсивный вызов
```
{% endraw %}

Здесь используется `functools.lru_cache` вместо самодельного кеша. Сама рекурсивная функция не изменилась. За работу с кешэм отвечает декоратор. Он предотвращает запуск функции, если в кэше есть значение для аргумента.
