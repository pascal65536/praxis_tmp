# Декораторы

Декоратор — это функция, которая принимает функцию и возвращает новую функцию.

## 1. Минимальный декоратор (без аргументов)

{% raw %}
```python
def my_decorator(func):  # На вход функции в качестве аргумента поступает другая функция
    def wrapper(*args, **kwargs):
        print("до вызова")
        result = func(*args, **kwargs)
        print("после вызова")
        return result
    return wrapper

@my_decorator
def greet(name):
    print(f"Привет, {name}!")
    return name.upper()

greet("Аня")
```
{% endraw %}

**Вывод:**

```
до вызова
Привет, Аня!
после вызова
```

`@my_decorator` — это просто синтаксический сахар над:

{% raw %}
```python
greet = my_decorator(greet)
```
{% endraw %}

## 2. Зачем *args, **kwargs

Без них декоратор работал бы только с функциями без аргументов. `*args`, `**kwargs` делают обёртку универсальной:

{% raw %}
```python
def log(func):
    def wrapper(*args, **kwargs):
        print(f"вызов {func.__name__} с args={args}, kwargs={kwargs}")
        return func(*args, **kwargs)
    return wrapper

@log
def add(a, b, c=0):
    return a + b + c

print(add(1, 2, c=10))   # вызов add с args=(1, 2), kwargs={'c': 10} => 13
```
{% endraw %}

## 3. Сохранение метаданных: functools.wraps

Без `wraps` функция теряет имя, докстринг и т.д.:

{% raw %}
```python
def log(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@log
def add(a, b):
    """Складывает два числа."""
    return a + b

print(add.__name__)   # 'wrapper' — плохо!
print(add.__doc__)    # None — плохо!
```
{% endraw %}

Исправляется одной строкой:

{% raw %}
```python
from functools import wraps

def log(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@log
def add(a, b):
    """Складывает два числа."""
    return a + b

print(add.__name__)   # 'add'
print(add.__doc__)    # 'Складывает два числа.'
```
{% endraw %}

Всегда используйте `@wraps` — это стандарт де-факто.

## 4. Декоратор с аргументами

Здесь нужен третий уровень вложенности: внешняя функция принимает параметры декоратора, средняя — саму функцию, внутренняя — аргументы вызова.

{% raw %}
```python
from functools import wraps

def repeat(times):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            result = None
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(times=3)
def say(msg):
    print(msg)
    return msg

say("ку")   # напечатает "ку" три раза
```
{% endraw %}

Как это читается: `say = repeat(times=3)(say)`.

## 5. Практический пример: замер времени

Классический полезный декоратор:

{% raw %}
```python
import time
from functools import wraps

def timed(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            elapsed = time.perf_counter() - start
            print(f"{func.__name__}: {elapsed:.6f} сек")
    return wrapper

@timed
def fib(n):
    a, b = 1, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return a

print(fib(200))
```
{% endraw %}

`try/finally` гарантирует, что время напечатается даже при исключении.

## 6. Cамодельный кеширующий декоратор

{% raw %}
```python
from functools import wraps

def memoize(func):
    cache = {}
    @wraps(func)
    def wrapper(n):
        if n not in cache:
            cache[n] = func(n)
        return wrapper.cache[n]
    wrapper.cache = cache
    return wrapper

@memoize
def f(n):
    if n in (0, 1):
        return 1
    return f(n - 1) + f(n - 2)

print(f(20))
print(f.cache)
```
{% endraw %}

Это ровно то, что делает `functools.lru_cache`, только проще.
