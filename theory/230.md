# Список (list)

Список в Python – это встроенный тип (класс) данных, представляющий собой одну из разновидностей структур данных. Структуру данных можно представить как сложную единицу, объединяющую в себе группу более простых. Каждая разновидность структур данных имеет свои особенности.

> Список – это изменяемая последовательность произвольных элементов.

В большинстве других языков программирования есть такой широко используемый тип данных как массив. В Питоне такого встроенного типа нет. Однако списки условно можно считать аналогом массивов за одним исключением. Составляющие массив элементы должны принадлежать одному типу данных, для списков такого ограничения нет.

Например, массив может содержать только целые числа или только вещественные числа или только строки. Список также может содержать элементы только одного типа, что делает его внешне неотличимым от массива. Но вполне допустимо, чтобы в одном списке содержались как числа, так и строки, а также что-нибудь еще.

Создавать списки можно разными способами. Создадим его простым перечисление элементов:

```bash
>>> a = [12, 3.85, "black", -4]
>>> a
[12, 3.85, 'black', -4]
>>> 
```

Здесь переменной `a` присвоен список. В Python список заключается в квадратные скобки. Он содержит четыре элемента. Чтобы обратиться к списку целиком, достаточно указать одну переменную `a`.

Элементы в списке упорядочены, имеет значение в каком порядке они расположены. Каждый элемент имеет свой индекс, или номер. **Индексация начинается с нуля.** В данном случае число 12 имеет индекс 0, строка "black" – индекс 2. Чтобы извлечь конкретный элемент, надо после имени переменной указать в квадратных скобках его индекс:

```bash
>>> a[0]
12
>>> a[3]
-4
>>> a[2]
'black'
>>>
```

Также как в строках, в списках доступна нумерация с конца.

```bash
>>> a[-1]
-4
>>> a[-2]
'black'
>>> a[-3], a[-4]
(3.85, 12)
```

Часто требуется извлечь не один элемент, а так называемый `срез` – часть списка. В этом случае указывается индекс первого элемента среза и индекс следующего за последним элементом среза:

```bash
>>> a[0:2]
[12, 3.85]
```

В данном случае извлекаются первые два элемента с индексами 0 и 1. Элемент с индексом 2 в срез уже не входит. В таком случае возникает вопрос, как извлечь срез, включающий в себя последний элемент? Если какой-либо индекс не указан, то считается, что имеется в виду начало или конец:

```bash
>>> a[:3]
[12, 3.85, 'black']
>>> a[2:]
['black', -4]
>>> a[:]
[12, 3.85, 'black', -4]
```

**Списки – изменяемые объекты.** Это значит, что в них можно добавлять элементы, удалять их, изменять существующие. Проще всего изменить значение элемента. Для этого надо обратиться к нему по индексу и перезаписать значение в заданной позиции:

```bash
>>> a[1] = 4
>>> a
[12, 4, 'black', -4]
```

Добавлять и удалять лучше с помощью специальных встроенных методов списка:

```bash
>>> a.append('wood')
>>> a
[12, 4, 'black', -4, 'wood']
>>> a.insert(1, 'circle')
>>> a
[12, 'circle', 4, 'black', -4, 'wood']
>>> a.remove(4)
>>> a
[12, 'circle', 'black', -4, 'wood']
>>> a.pop()
'wood'
>>> a
[12, 'circle', 'black', -4]
>>> a.pop(2)
'black'
>>> a
[12, 'circle', -4]
```

Перечень всех методов списка можно узнать с помощью встроенной в Python функции `dir()`, передав в качестве аргумента переменную, связанную со списком, или название класса (в данном случае – `list`). В полученном из `dir()` списке надо смотреть имена без двойных подчеркиваний.

Для получения информации о конкретном методе следует воспользоваться встроенной функцией `help()`, передав ей в качестве аргумента имя метода, связанное с объектом или классом. Например, `help(a.pop)` или `help(list.index)`. Выход из справки – q.

Можно изменять списки не используя методы, а с помощью взятия и объединения срезов:

```bash
>>> b = [1, 2, 3, 4, 5, 6]
>>> b = b[:2] + b[3:]
>>> b
[1, 2, 4, 5, 6]
```

Здесь берется срез из первых двух элементов и срез, начиная с четвертого элемента (индекс 3) и до конца. После чего срезы объединяются с помощью оператора "сложения".

Можно изменить не один элемент, а целый срез:

```bash
>>> mylist = ['ab','ra','ka','da','bra']
>>> mylist[0:2] = [10,20]
>>> mylist
[10, 20, 'ka', 'da', 'bra']
```

Пример создания пустого списка с последующим заполнением его в цикле случайными числами:

```bash
>>> import random
>>> c = []
>>> i = 0
>>> while i < 10:
...     c.append(random.randint(0,100))
...     i += 1
...
>>> c
[30, 44, 35, 77, 53, 44, 49, 17, 61, 82]
```

## Сортировка списков

Сортировка в Python выполняется с помощью `sorted()` и `list.sort()`.

Функция `sorted()`, работает с итерируемыми объектами. Для списка есть свой метод для сортировки - методом `list.sort()`

### Сортировка функцией sorted()

Запустим в консоли небольшой код, чтобы проверить, как работает функция `sorted()`

```bash
>>> test = [1, 4, 7, 0, 9, 3, 2, 8]
>>> sorted(test)
[0, 1, 2, 3, 4, 7, 8, 9]
>>> test
[1, 4, 7, 0, 9, 3, 2, 8]
>>>  
```

Здесь видно, что функция `sorted()` возвращает отсортированный список, не изменяя сам список, переданный в функцию как аргумент.

### Сортировка методом списков list.sort()

Для сортировки можно использовать метод списков `list.sort()`, который изменяет исходный список (и возвращает `None` во избежание путаницы). Вы можете использовать `list.sort()`, если дальше планируете работать с этим списком и не хотите создавать новый и тратить память. Если хотите сохранить исходный порядок следования элементов в списке, то создавайте новый, отсортированный с помощью функции `sorted()`

```bash
>>> foo = ['1', '12', '123', '2', '3', '0', '4', 'a', '6', '8']
>>> foo.sort()
>>> foo
['0', '1', '12', '123', '2', '3', '4', '6', '8', 'a']
>>>      
```

Здесь видно, что список foo изменился после того, как мы применили метод `sort()`. Обратите внимание, что метод `sort()` вернул None, в отличие от `sorted()`.

Добавим, что `sorted()` можно применять для других типов данных, не только для списков.

Во всех примерах списки были отсортированы по возрастанию. Есть способ отсортировать по убыванию, для этого применим параметр `reverse=True`

```bash
>>> foo = ['1', '12', '123', '2', '3', '0', '4', 'a', '6', '8']
>>> foo.sort()
>>> foo
['0', '1', '12', '123', '2', '3', '4', '6', '8', 'a']
>>> foo.sort(reverse=True)
>>> foo
['a', '8', '6', '4', '3', '2', '123', '12', '1', '0']
>>>         
```

Если сортировать надо не по значению элементу списку, а по какому-либо признаку, то применим параметр `key`

```bash
>>> foo.sort(reverse=True, key=len)
>>> foo
['123', '12', 'a', '8', '6', '4', '3', '2', '1', '0']
>>>                                                    
```

Здесь список отсортирован по длине строки.

Аналогично с `sorted()`

```bash
>>> test_lst = [1, -2, 3, 4, 7, 5, -9, 0, -4]
>>> sorted(test_lst)
[-9, -4, -2, 0, 1, 3, 4, 5, 7]
>>> sorted(test_lst, reverse=True)
[7, 5, 4, 3, 1, 0, -2, -4, -9]
>>> sorted(test_lst, reverse=True, key=abs)
[-9, 7, 5, 4, -4, 3, -2, 1, 0]
>>>          
```

Здесь видно, что список отсортирован по возрастанию, затем по убыванию и применяя `key=abs` список отсортировали по убыванию абсолютного значения.

## Коротко

Списки в Python — это мощный и гибкий инструмент для работы с последовательностями данных. Давайте подробнее рассмотрим их особенности и возможности.

### Основные характеристики списков

- *Изменяемость*: Списки в Python являются изменяемыми, что означает, что вы можете изменять их содержимое после создания.
- *Упорядоченность*: Элементы в списке сохраняют порядок, в котором были добавлены, и могут быть доступны по индексу.
- *Разнородность*: Списки могут содержать элементы различных типов (числа, строки, другие списки и т.д.).

### Создание списков

Списки можно создавать несколькими способами. Наиболее распространенный способ — это перечисление элементов в квадратных скобках:

```python
a = [123, 3.1415, "black", -432]
print(a)  
# Вывод: [123, 3.1415, 'black', -432]
```
                   
### Индексация и срезы

Каждый элемент списка имеет свой индекс, начиная с нуля:

```python
a = [123, 3.1415, "black", -432]
print(a[0])  # Вывод: 123
print(a[2])  # Вывод: 'black'
```

Можно использовать отрицательные индексы для доступа к элементам с конца списка:

```python
a = [123, 3.1415, "black", -432]
print(a[-1])  # Вывод: -432
print(a[-2])  # Вывод: 'black'
```
                      
Срезы позволяют извлекать подмножества элементов из списка:

```python
a = [123, 3.1415, "black", -432]
print(a[0:2])  # Вывод: [123, 3.1415]
print(a[:3])   # Вывод: [123, 3.1415, 'black']
print(a[2:])   # Вывод: ['black', -432]
```

### Изменение списков

Списки можно изменять, добавляя, удаляя или изменяя элементы. Например, можно изменить значение элемента по индексу:

```python
a = [123, 3.1415, "black", -432]
a[1] = 4
print(a)  # Вывод: [123, 4, 'black', -432]
```

### Добавление элементов

Для добавления элементов в список используются методы append() и insert():

```python
a = [123, 3.1415, "black", -432]
a.append('smith')
print(a)  
# Вывод: [123, 3.1415, 'black', -432, 'smith']

a.insert(1, 'hammer')
print(a)  # Вывод: [123, 'hammer', 3.1415, 'black', -432, 'smith']
```

### Удаление элементов

Элементы можно удалять с помощью методов remove() и pop():

```python
a = [123, 'hammer', 3.1415, 'black', -432, 'smith']

a.remove(-432)
print(a)  # Вывод: [123, 'hammer', 3.1415, 'black', 'smith']

removed_item = a.pop()
print(removed_item)  # Вывод: 'smith'
print(a)  # Вывод: [123, 'hammer', 3.1415, 'black']

removed_item = a.pop(2)
print(removed_item)  # Вывод: 3.1415
print(a)  # Вывод: [123, 'hammer', 'black']
```

### Объединение и изменение срезов

Можно объединять списки и изменять их с помощью срезов:

```python
b = [1, 2, 3, 4, 5, 6]
b = b[:2] + b[3:]  # Удаляем элемент с индексом 2
print(b)  # Вывод: [1, 2, 4, 5, 6]

# Изменение целого среза
b[1:3] = ['a', 'b']  # Заменяем элементы с индексами 1 и 2
print(b)  # Вывод: [1, 'a', 'b', 5, 6]
```

### Методы списков

Списки имеют множество встроенных методов. Чтобы узнать о доступных методах, вы можете использовать функцию dir():

```python
print(dir(a))  # Перечень методов списка
```
Для получения информации о конкретном методе можно воспользоваться функцией help():

```python
help(a.append)  # Информация о методе append
```
