## print()

`print()` печатает параметр в консоль. Функция "всеядна", в качестве параметра (в скобках) мы можем передать что угодно, а функция попытается это напечатать.

```python
print('Python')  # Вывод Python
print(2*3)  # Вывод 6
print(1,2,3,4,5)  # Вывод 1 2 3 4 5
print(print)  # Вывод <built-in function print>
```

Функция напечатала слово Python, результат математической операции, несколько чисел, перечисленных через запятую. Причем на печати запятых нет. И попыталась напечатать служебное слово `print` и мы узнали что это встроенная функция.

```python
print('1', 'два', 3)  # Вывод 1 два 3
```

Здесь функции передали три параметра, перечислив их через запятую.

В Python, **параметр** - это переменная, которая передается в функцию или метод при ее вызове.

Проще говоря: это информация, которую вы "подаете" функции на вход, чтобы она могла выполнить свою задачу.

Парметры могут быть разного типа.

```python
print('P', 'y', 't', 'h', 'o', 'n') # Вывод P y t h o n
```

Мы не можем просто взять и напечатать буквы рядом, почему-то появляются пробелы. Это не простой пробел - это *разделитель*. Мы можем от них избавиться, указав другой разделитель. Разделитель мы тоже подаём на вход функции в качестве параметра, в этот раз именованного. Обратите внимание, что к именованному параметру `sep` функция `print()` относится по-особенному и не печатает его, как остальные параметры.

```python
print('P', 'y', 't', 'h', 'o', 'n', sep='')  # Вывод Python
```

Поиграем с разделителем

```python
print('P', 'y', 't', 'h', 'o', 'n', sep='.')  
# Вывод P.y.t.h.o.n
```

Поробуем разделитель поинтереснее

```print
print('стеклянный', 'оловянный', 'деревянный', sep='; ')
# Вывод стеклянный; оловянный; деревянный
```

Посмотрите, какой разделитель мы запросили - это запятая и пробел. Такое разделитель уместно использовать, если нужно что-то перечислять через запятую, причём в конце перечня запятой не будет.

Как вы поняли, разделителем может быть любая строка.

В Python, как и во многих других языках программирования, есть специальные комбинации символов, называемые *escape-последовательностями*, которые используются для представления непечатаемых символов или для управления форматированием текста.

## **Escape-последовательности:**

`\n`(Newline): Начинает новую строку.

`\t`(Tab) Вставляет символ табуляции, который обычно соответствует 4 или 8 пробелам.

`\r`(Newline): Переносит курсор на начало текущей строки.

`\b `(Carriage Return): Удаляет предыдущий символ.

`\\ `(Backslash): Вставляет символ обратной косой черты.

`\' `(Single quote): Вставляет символ одинарной кавычки.

`\" `(Double quote): Вставляет символ двойной кавычки.

### 1. Когда нужно напечатать ответ в столбик:

```python
print('Дама сдавала в багаж:', 'Диван', 'Чемодан', 'Саквояж', sep='\n')  
# Используем Newline
```

**Вывод**

```text
Дама сдавала в багаж:
Диван
Чемодан
Саквояж
```

### 2. Когда лучше дать ответ в виде таблицы:

```python
print('X', 'Y', '&', sep='\t')
print(0, 1, 1, sep='\t')
print(1, 1, 1, sep='\t')
print(1, 0, 1, sep='\t')
print(0, 0, 0, sep='\t')
```

**Вывод**

```
X       Y       &
0       1       1
1       1       1
1       0       1
0       0       0
```

### 3. Когда внутри строк нужно использовать кавычки, но мы эти кавычки уже использовали, для того, чтобы создать строку.

```python
print("Python назван в честь \"Летающего цирка\" Монти Пайтона")

# Вывод: Python назван в честь "Летающего цирка" Монти Пайтона
```

## input()

`input()` используется тогда, когда вы хотите чтобы пользователь что-то ввёл с клавиатуры. Работа программы останавливается до тех пор, пока не будет нажата клавиша `Enter`.

Пока пользователь не набрал что-то на клавиатуре и не нажал `Enter`, программа находится в режиме ожидания.

Результат выполнения функции `input()` можно присвоить какой-либо переменной, чтобы использовать его в дальнейшем.

```python
word = input()
```

Параметром функции может быть строка-подсказка. Что именно нужно ввести и почему остановилась программа.

```python
result = input('Сколько будет 3*9? Подумай, напиши ответ и нажми Enter ')
```

Результат выполнения функции `input()` - строка.

> Для корректной работы тестирующей системы нужно разделять ввод и вывод, используя функцию `input()` без параметров и функцию `print()`.

Над строками можно производить следующие операции:

- сложение (конкатенация строк);
- умножение строки на целое число.

Результатом сложения строк будет новая строка, представляющая собой записанные последовательно складываемые строки (строки как бы склеиваются друг с другом, образуя новую строку).

```python
print("Сложно" + "подчинённый") 
# Вывод Сложноподчинённый
```

При умножении строки на целое число `n` получается новая строка, состоящая из `n` дублирований исходной строки. Например, выведем 10 символов `-` подряд:

```
print("-" * 10)  # Вывод ----------
```
