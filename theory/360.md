# Работа с датой и временем в Python (datetime)

## 1. Зачем это нужно?

В реальной разработке и ИБ время — это критически важный ресурс:

- *Backend (Flask/Django)*: Срок действия JWT-токенов, время создания сессии, планировщик задач (Celery).

- *InfoSec / SAST*: Анализ логов, определение времени атаки, расчет времени отклика (Time-of-Check to Time-of-Use уязвимости).

- *Базы данных*: Фильтрация записей по дате.

Объекты `datetime` в Python **неизменяемы (immutable)**. Любая операция (например, добавление дня) возвращает новый объект, а не меняет старый. Это делает их безопасными для использования в многопоточных приложениях.

## 2. Четыре "кита" модуля datetime

Модуль предоставляет несколько классов.

{% raw %}
```python
import datetime

# 1. date: Только дата (год, месяц, день). Идеально для дней рождения.
d = datetime.date(2026, 9, 21)
print(d)  # 2026-09-21

# 2. time: Только время суток. Идеально для расписания звонков.
t = datetime.time(14, 30, 0)
print(t)  # 14:30:00

# 3. datetime: Дата и время вместе. Самый частый выбор для логов.
dt = datetime.datetime(2026, 9, 21, 14, 30, 0)
print(dt) # 2026-09-21 14:30:00

# 4. timedelta: Разница (интервал) между двумя моментами времени.
delta = datetime.timedelta(days=2, hours=5)
print(dt + delta) # 2026-09-23 19:30:00
```
{% endraw %}

## 3. Главная мнемоника: strptime vs strftime

| Метод | Расшифровка | Направление | Аналогия |
|-------|-------------|-------------|----------|
| strptime | String **P**arse Time | Строка -> Объект `datetime` | **P**arse (Разобрать строку на части) |
| strftime | String **F**ormat Time | Объект `datetime` -> Строка | **F**ormat (Отформатировать в строку) |

#### Шпаргалка по директивам формата:

- `%Y` — год (4 цифры, `2026`)

- `%m` — месяц (`09`)

- `%d` — день (`21`)

- `%H` — часы 24ч (`14`)

- `%M` — минуты (`30`)

- `%S` — секунды (`05`)

- `%f` — микросекунды (важно для логов)

### 4. Практикум на реальных логах

#### Задача А: 

Формат времени в логе: `2026-09-02 08:59:21,734`

{% raw %}
```python
from datetime import datetime

log_line = "2026-09-02 08:59:21,734;vkkbot_1618082;INFO;REQUEST;871865067;10Г"

# 1. Извлекаем строку времени (до первой точки с запятой)
time_str = log_line.split(';')[0]

# 2. Преобразуем строку в объект datetime (strptime)
# Обратите внимание на %f для миллисекунд
dt_obj = datetime.strptime(time_str, "%Y-%m-%d %H:%M:%S,%f")

print(f"Объект: {dt_obj}")
print(f"Час запроса: {dt_obj.hour}") # 8

# 3. Форматируем обратно в человекочитаемый вид (strftime)
readable = dt_obj.strftime("%d.%m.%Y в %H:%M")
print(f"Человеческий вид: {readable}") # 02.09.2026 в 08:59
```                                   
{% endraw %}

#### Задача Б:

Формат времени: `19/Sep/2026:12:45:32 +0300` (английский месяц и часовой пояс).

{% raw %}
```python
from datetime import datetime

nginx_time = "19/Sep/2026:12:45:32 +0300"

# %b - сокращенное название месяца на языке локали (Sep)
# %z - часовой пояс (поддерживается в Python 3.2+)
dt_nginx = datetime.strptime(nginx_time, "%d/%b/%Y:%H:%M:%S %z")

print(f"С часовым поясом: {dt_nginx}")
print(f"UTC время: {dt_nginx.utctimetuple()}")
```
{% endraw %}

## 5. Современные практики и InfoSec-нюансы

### 1. Используйте fromisoformat() вместо strptime

Если строка уже в формате `ISO 8601 (YYYY-MM-DDTHH:MM:SS)`, никогда не используйте strptime. Метод `fromisoformat()` работает в разы быстрее и безопаснее (защищен от некоторых видов DoS при парсинге сложных регулярных выражений внутри `strptime`).

{% raw %}
```python
# Плохо (медленнее, сложнее):
# dt = datetime.strptime("2026-09-21T10:00:00", "%Y-%m-%dT%H:%M:%S")

# Хорошо (быстро и безопасно):
dt = datetime.fromisoformat("2026-09-21T10:00:00")
```
{% endraw %}

### 2. Naive vs Aware объекты (Часовые пояса)

- *Naive (наивный)*: Объект без информации о часовом поясе (`tzinfo=None`). Python не знает, это время по Москве или по Лондону. Опасно для хранения в БД или сравнения.

- *Aware (осведомленный)*: Объект с указанием пояса.

{% raw %}
```python
# Плохо (медленнее, сложнее):
# dt = datetime.strptime("2026-09-21T10:00:00", "%Y-%m-%dT%H:%M:%S")

# Хорошо (быстро и безопасно):
dt = datetime.fromisoformat("2026-09-21T10:00:00")
```
{% endraw %}

**Правило InfoSec**: Всегда храните время в базах данных в формате `UTC` (aware), а конвертируйте в локальное время только на этапе отображения пользователю.
