## Объектно-ориентированное программирование (ООП)

Объектно-ориентированное программирование (ООП) — это парадигма программирования, основанная на концепции "объектов", которые могут содержать данные и код: данные в виде полей (атрибутов или свойств), а код в виде процедур (методов). Основные принципы ООП включают:

 **Инкапсуляция**: Это механизм, который объединяет данные и методы, работающие с этими данными, в одном объекте. Инкапсуляция позволяет скрыть внутреннее состояние объекта от внешнего мира, предоставляя доступ только через определенные методы.
 
 **Наследование**: Позволяет создавать новые классы на основе существующих. Новый класс (наследник) наследует свойства и методы родительского класса, что способствует повторному использованию кода и упрощает его поддержку.
 
 **Полиморфизм**: Это способность объектов разных классов обрабатывать сообщения (методы) одинаково, хотя они могут реализовывать эти методы по-разному. Полиморфизм позволяет использовать один интерфейс для работы с различными типами объектов.
 
 **Абстракция**: Это процесс выделения общих характеристик объектов и игнорирование несущественных деталей. Абстракция позволяет сосредоточиться на том, что делает объект, а не на том, как он это делает.

## Основные понятия ООП:

 **Класс** — это шаблон для создания объектов. Он определяет свойства (атрибуты) и методы (функции), которые будут у объектов.

 **Объект** — это экземпляр класса.

 **Атрибуты** — это переменные, которые хранят данные объекта.

 **Методы** — это функции, которые работают с данными объекта.

## Пример класса `Dog`:

Создадим класс `Dog`, который будет описывать собаку.

```python
class Dog:
    # Конструктор класса (вызывается при создании объекта)
    def __init__(self, name, age, color):
        self.name = name  # Атрибут: имя собаки
        self.age = age    # Атрибут: возраст собаки
        self.color = color  # Атрибут: цвет собаки

    # Метод: собака лает
    def say(self):
        print(f"{self.name} говорит: Гав-гав!")

    # Метод: информация о собаке
    def info(self):
        print(f"Собака по имени {self.name}, возраст {self.age} лет. Цвет - {self.color}")

# Создаем объект (экземпляр) класса Dog
my_dog = Dog("Бобик", 3, "чёрный")

# Вызываем методы объекта
my_dog.say()  # Бобик говорит: Гав-гав!
my_dog.info()  # Собака по имени Бобик, возраст 3 лет. Цвет - чёрный
```

### Что здесь происходит:

1. Мы создали класс `Dog` с помощью ключевого слова `class`.
2. В конструкторе `__init__` задали атрибуты `name` , `age` и `color`.
3. Добавили методы `say` (собака лает) и `info` (выводит информацию о собаке).
4. Создали объект `my_dog` класса `Dog` и вызвали его методы.

### Как это работает:

- Когда мы создаем объект (`my_dog = Dog("Бобик", 3, "чёрный")`), вызывается метод `__init__`, который инициализирует атрибуты.
- Методы (`say`, `info`) работают с данными конкретного объекта.

Давай создадим класс `Cat` для кошки. Он будет похож на класс `Dog`, но с кошачьими особенностями.

## Пример класса `Cat`:

```python
class Cat:
    # Конструктор класса
    def __init__(self, name, age, color):
        self.name = name  # Атрибут: имя кошки
        self.age = age    # Атрибут: возраст кошки
        self.color = color  # Атрибут: цвет кошки

    # Метод: кошка мяукает
    def say(self):
        print(f"{self.name} говорит: Мяу-мяу!")

    # Метод: кошка спит
    def sleep(self):
        print(f"{self.name} спит. Тссс...")

    # Метод: информация о кошке
    def info(self):
        print(f"Кошка по имени {self.name}, возраст {self.age} лет, цвет {self.color}.")

# Создаем объект (экземпляр) класса Cat
my_cat = Cat("Мурка", 2, "рыжий")

# Вызываем методы объекта
my_cat.say()  # Мурка говорит: Мяу-мяу!
my_cat.sleep()  # Мурка спит. Тссс...
my_cat.info()  # Кошка по имени Мурка, возраст 2 лет, цвет рыжий.
```

### Что мы добавили:

1. Новый атрибут `color` (цвет кошки).
2. Метод `meow` (кошка мяукает).
3. Метод `sleep` (кошка спит).

### Как это работает:

- Когда мы создаем объект (`my_cat = Cat("Мурка", 2, "рыжий")`), вызывается конструктор `__init__`, который задает атрибуты.
- Методы `meow`, `sleep` и `info` работают с данными конкретного объекта.

Теперь у нас есть два класса: `Dog` и `Cat`. Теперь можно завести сколько угодно кошек и собак.

## Преимущества ООП:

- Упрощение разработки: Код становится более структурированным и легче поддерживается.
- Повторное использование кода: Благодаря наследованию и полиморфизму можно использовать уже написанный код.
- Модульность: Объекты могут быть разработаны и протестированы независимо друг от друга.
