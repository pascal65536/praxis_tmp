## Декоратор @property

Декоратор `@property` в Python используется для создания свойств (*properties*) в классах. Он позволяет вам определять методы, которые можно вызывать как атрибуты, что упрощает доступ к данным и инкапсуляцию.

### Основные преимущества использования @property:

1. **Инкапсуляция**: Позволяет скрыть внутренние детали реализации.
2. **Контроль доступа:** Вы можете добавлять логику при получении или установке значений.
3. **Удобство**: Позволяет использовать методы как атрибуты, что делает код более читаемым.

### Синтаксис

Вот базовый пример использования декоратора `@property`:

```
class Circle:
    def __init__(self, radius):
        self._radius = radius  # Используем _radius для обозначения защищенного атрибута

    @property
    def radius(self):
        """Получить радиус круга."""
        return self._radius

    @radius.setter
    def radius(self, value):
        """Установить радиус круга."""
        if value < 0:
            raise ValueError("Радиус не может быть отрицательным!")
        self._radius = value

    @property
    def area(self):
        """Вычислить площадь круга."""
        return 3.14159 * (self._radius ** 2)

# Пример использования
circle = Circle(5)
print(circle.radius)  # Вывод: 5
print(circle.area)  # Вывод: 78.53975

circle.radius = 10  # Установка нового радиуса
print(circle.area)  # Вывод: 314.159
```

### Объяснение:

1. **Атрибуты:** Мы используем `_radius` как защищенный атрибут, чтобы избежать прямого доступа к нему извне.
2. **Декоратор @property:** Метод `radius` становится свойством, и его можно вызывать как атрибут.
3. **Сеттер:** Метод с декоратором `@radius.setter` позволяет устанавливать значение радиуса с проверкой на отрицательные значения.
4. **Вычисляемое свойство:** Метод `area` также является свойством, которое вычисляет площадь круга на основе текущего радиуса.

Использование декоратора `@property` делает ваш код более чистым и понятным, а также предоставляет удобный способ управления доступом к атрибутам класса.
