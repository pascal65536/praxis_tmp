Под виртуальным окружением в Python будем понимать изолированное рабочее пространство для проектов. Если программист работает над несоклькими проектами одновременно, то у него будет различаться набор установленных модулей. Если модули устанавливать глобально, для всей операционной системы, то рано или поздно начнётся конфликт версий. А при попытке автоматически создать файл со списком необходимых пакетов, вы перечислите все, что у вас установлено.

```bash
sudo apt install python3.10-venv

python -m venv .venv

source .venv/bin/activate

pip list

pip install flask

pip freeze > requirements.txt
```
