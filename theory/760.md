# Message-Digest Algorithm 5

MD5 (Message-Digest Algorithm 5) - это криптографическая хэш-функция, которая генерирует 128-битный хэш (отпечаток) из произвольного блока данных.

Представьте, что у вас есть документ. Вы хотите убедиться, что он не был изменен. Вы можете использовать MD5 для создания уникального "отпечатка" этого документа. Если кто-то изменит документ, даже одну букву, "отпечаток" изменится. Модуль `hashlib` в Python позволяет вам легко создать этот "отпечаток" (хеш) и сравнить его с другим "отпечатком" для проверки целостности документа.

**Пример использования:**

{% raw %}
```python
import hashlib


data = "Это мой текст".encode('utf-8')
md5_hash = hashlib.md5(data).hexdigest()
print(md5_hash)
```
{% endraw %}

Этот код вычисляет MD5-хеш строки "Это мой текст" и выводит его в шестнадцатеричном формате.

## MD5-хеш файлов

Этот пример демонстрирует, как вычислить MD5-хеш файла в Python с использованием модуля `hashlib`:

{% raw %}
```python
import hashlib


def calculate_md5_hash(filename):
  """
  Вычисляет MD5-хеш файла.
  """
  hash_md5 = hashlib.md5()
  with open(filename, "rb") as f:
    for chunk in iter(lambda: f.read(4096), b""):
      hash_md5.update(chunk)
  return hash_md5.hexdigest()

filename = 'my_app.txt'

md5_hash = calculate_md5_hash(filename)
print(f"MD5-хеш файла '{filename}': {md5_hash}")
```
{% endraw %}

**Что тут происходит:**

- **Импорт модуля hashlib**: Этот модуль предоставляет функции для работы с хэш-функциями, включая MD5.
- **Определение функции calculate_md5_hash**: Эта функция принимает имя файла в качестве аргумента и возвращает его MD5-хеш в виде шестнадцатеричной строки.
- **Создание объекта hashlib.md5()**: Создается объект `hashlib.md5`, который будет использоваться для вычисления хеша.
- **Открытие файла в бинарном режиме чтения**: Файл открывается в бинарном режиме ("rb"), так как MD5-хеш вычисляется на основе бинарных данных.
- **Итерация по файлу по частям**: Файл считывается по частям (по 4096 байт) с помощью `iter` и `f.read(4096)`. Это позволяет обрабатывать большие файлы без загрузки их целиком в память.
- **Обновление хеша**: Для каждой части файла вызывается метод `hash_md5.update()`, который обновляет текущий хеш.
- **Получение шестнадцатеричного представления хеша**: После обработки всего файла вызывается метод `hash_md5.hexdigest()`, который возвращает шестнадцатеричное представление вычисленного хеша.
- **Вывод хеша**: Выводится MD5-хеш файла на консоль.

**Как использовать:**

1. Замените `'my_app.txt'` на фактический путь к файлу, для которого вы хотите вычислить хеш.
2. Запустите скрипт Python.
3. Результат (MD5-хеш) будет выведен на консоль.
