# Что такое логирование?

Логирование — это процесс записи информации о работе программы в ходе её выполнения. Логи (журналы событий) содержат данные о том, что происходит в приложении: какие действия выполняются, какие ошибки возникают, и другую полезную информацию.

## Для чего используется логирование?

*Отладка:* Логи помогают находить и исправлять ошибки в коде.
Например, если программа падает, можно посмотреть логи и понять, на каком этапе произошла ошибка.

*Мониторинг:* Логи позволяют отслеживать состояние программы в реальном времени.
Например, можно узнать, сколько пользователей запустили бота или какие команды они использовали.

*Анализ:* Логи помогают анализировать поведение пользователей или системы.
Например, можно понять, какие функции приложения используются чаще всего.

*Аудит:* Логи фиксируют важные события, что полезно для соблюдения нормативных требований или расследования инцидентов.

## Какое бывает логирование?

**По уровню детализации:**

*DEBUG*: Подробная информация для отладки (например, значения переменных).

*INFO*: Общая информация о работе программы (например, запуск бота или получение сообщения).

*WARNING*: Предупреждения о потенциальных проблемах (например, нехватка памяти).

*ERROR*: Ошибки, которые мешают нормальной работе программы (например, сбой подключения к базе данных).

*CRITICAL*: Критические ошибки, которые могут привести к остановке программы (например, отсутствие важного файла).

**По месту хранения:**

*Консоль*: Логи выводятся в терминал.

*Файл*: Логи записываются в файл.

*Сеть*: Логи отправляются на удаленный сервер (например, в систему мониторинга).

**По формату:**

*Текстовый формат*: Простые текстовые сообщения.

*JSON*: Логи в формате JSON, удобном для машинной обработки.

*Структурированный формат*: Логи с четкой структурой (например, с указанием времени, уровня и сообщения).

### Пример 1: Логирование в консоль

{% raw %}
```python
import logging

# Настройка логирования
logging.basicConfig( level=logging.INFO, format="%(levelname)s: %(message)s",)

# Пример использования
logging.info("Это информационное сообщение.")
logging.warning("Это предупреждение.")
logging.error("Это сообщение об ошибке.")
```

### Пример 2: Логирование в файл

{% raw %}
```python
import logging

# Настройка логирования
logging.basicConfig(level=logging.INFO, format="%(asctime)s - %(levelname)s - %(message)s", filename="app.log",)

# Пример использования
logging.info("Это сообщение будет записано в файл.")
logging.error("Это сообщение об ошибке тоже будет записано.")
```

### Пример 4: Логирование с обработкой исключений

{% raw %}
```python
import logging

# Настройка логирования
logging.basicConfig(level=logging.INFO, format="%(levelname)s: %(message)s",)

# Пример функции с обработкой исключений
def divide(a, b):
    try:
        result = a / b
        logging.info(f"Результат деления: {result}")
    except Exception as e:
        logging.error(f"Ошибка: {e}", exc_info=True)

# Пример использования
divide(10, 2)
divide(10, 0)
```
