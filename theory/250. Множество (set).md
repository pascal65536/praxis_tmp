## Множества

Множество — это неупорядоченная коллекция уникальных элементов.
### Свойства Множества

**Уникальность**: Каждый элемент в множестве встречается только один раз.

**Неупорядоченность**: Элементы не имеют определенного порядка, и их позиция в множестве не имеет значения.
### Операции с Множествами

Множества поддерживают различные операции, которые часто используются в математике и программировании:

**Объединение** (Union): Объединение двух множеств A и B — это множество, содержащее все элементы, которые есть в A, в B или в обоих. В Python это можно сделать с помощью оператора |: `A | B`.

**Пересечение** (Intersection): Пересечение двух множеств A и B — это множество, содержащее только те элементы, которые есть и в A, и в B. В Python это можно сделать с помощью оператора &: `A & B`.

**Разность** (Difference): Разность множеств A и B — это множество, содержащее элементы, которые есть в A, но отсутствуют в B. В Python это можно сделать с помощью оператора -: `A - B`.

**Симметричная разность** (Symmetric Difference): Симметричная разность множеств A и B — это множество, содержащее элементы, которые есть в A или в B, но не в обоих. В Python это можно сделать с помощью оператора ^: `A ^ B`.
### Примеры

В Python множества обозначаются с помощью фигурных скобок `{}` или функции `set()`. Вот несколько примеров:

**Создание множеств**

```python
A = {1, 2, 3, 4}

B = {3, 4, 5, 6}
```

**Объединение**

```python
union = A | B  # Вывод {1, 2, 3, 4, 5, 6}
```

**Пересечение**

```python
intersection = A & B  # Вывод {3, 4}
```

**Разность**

```python
difference = A - B  # Вывод {1, 2}
```

**Симметричная разность**

```python
sym_diff = A ^ B  # Вывод {1, 2, 5, 6}
```

### Методы Множеств

Множества в Python имеют множество полезных методов:

- `add(element)`: Добавляет элемент в множество.
- `remove(element)`: Удаляет элемент из множества. Если элемент не найден, вызывает ошибку.
- `discard(element)`: Удаляет элемент из множества. Если элемент не найден, не вызывает ошибку.
- `clear()`: Удаляет все элементы из множества.
- `union(other_set)`: Возвращает объединение двух множеств.
- `intersection(other_set)`: Возвращает пересечение двух множеств.
- `difference(other_set)`: Возвращает разность двух множеств.
- `symmetric_difference(other_set)`: Возвращает симметричную разность двух множеств.

#### add(element)

**Описание**: Добавляет элемент в множество.

```python
A = {5, 'Hello', 3.2}
A.add(2)
print(A)  # Вывод: {2, 'Hello', 3.2, 5}
```

#### discard(element)

**Описание**: Удаляет элемент из множества, если он присутствует. Если элемент не найден, не вызывает ошибку.

```python
A = {5, 'Hello', 3.2}
A.discard(3.2)
print(A)  # Вывод: {'Hello', 5}
```

#### remove(element)

**Описание**: Удаляет элемент из множества. Если элемент не найден, вызывает ошибку KeyError.

```
A = {5, 'Hello', 3.2}
A.remove(3.2)
print(A)  # Вывод: {'Hello', 5}
```

#### pop()

**Описание**: Удаляет и возвращает произвольный элемент из множества. Поскольку множества неупорядочены, нельзя предсказать, какой элемент будет удален.

```python
A = {5, 2, 8}
element = A.pop()
print(element)  # Вывод: один из элементов: 2, 5 или 8
print(A)  # Вывод: оставшиеся элементы
```

#### intersection(other_set)

**Описание**: Возвращает пересечение текущего множества с другим множеством.

```python
A = {5, 2, 8}
B = {5, 1}
result = A.intersection(B)
print(result)  # Вывод: {5}
```

#### issubset(other_set)

**Описание**: Проверяет, является ли текущее множество подмножеством другого множества.

```python
A = {1, -2}
B = {-2, 1, 3}
result = A.issubset(B)
print(result)  # Вывод: True
```

#### issuperset(other_set)

**Описание**: Проверяет, является ли текущее множество надмножеством другого множества.

```python
A = {-2, 1, 3}
B = {1, -2}
result = A.issuperset(B)
print(result)  # Вывод: True
```

#### isdisjoint(other_set)

**Описание**: Проверяет, являются ли два множества непересекающимися (не имеют общих элементов).

```python
A = {1, 2, 3}
B = {4, 6}
result = A.isdisjoint(B)
print(result)  # Вывод: True
```

#### clear()

**Описание**: Удаляет все элементы из множества, оставляя его пустым.

```python
A = {1, 2, 3, 4}
A.clear()
print(A)# Output: set()
```

#### union(other_set)

**Описание**: Возвращает новое множество, содержащее все элементы из обоих множеств. Это объединение двух множеств.

```python
A = {1, 2, 3}
B = {3, 4, 5}
C = A.union(B)
print(C)  # Вывод: {1, 2, 3, 4, 5}
```

Альтернативный синтаксис: `A | B`
#### intersection(other_set)

**Описание**: Возвращает новое множество, содержащее только те элементы, которые присутствуют в обоих множествах. Это пересечение двух множеств.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
C = A.intersection(B)
print(C)  # Вывод: {3, 4}
```

Альтернативный синтаксис: `A & B`

#### difference(other_set)

**Описание**: Возвращает новое множество, содержащее элементы, которые есть в первом множестве, но отсутствуют во втором. Это разность двух множеств.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
C = A.difference(B)
print(C)  # Вывод: {1, 2}
```

Альтернативный синтаксис: `A - B`
#### symmetric_difference(other_set)

**Описание**: Возвращает новое множество, содержащее элементы, которые есть в одном из множеств, но не в обоих. Это симметричная разность двух множеств.

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
C = A.symmetric_difference(B)
print(C)# Output: {1, 2, 5, 6}
```

Альтернативный синтаксис: `A ^ B`

**Пример использования**

```python
A = {1, 2, 3}
B = {3, 4, 5}

# Объединение
print(A.union(B))# Output: {1, 2, 3, 4, 5}

# Пересечение
print(A.intersection(B))# Output: {3}

# Разность
print(A.difference(B))# Output: {1, 2}

# Симметричная разность
print(A.symmetric_difference(B))# Output: {1, 2, 4, 5}
```

**Множества полезны в ситуациях, когда:**

- Нужно убедиться, что все элементы уникальны.
- Требуется выполнить математические операции, такие как объединение, пересечение и разность.
- Необходимо проверять наличие элементов в коллекции.

### Недостатки Множеств

- **Неупорядоченность**: Если порядок элементов важен, множества не подходят.
- **Отсутствие индексации**: Нельзя получить элемент по индексу, как в списках или кортежах.
