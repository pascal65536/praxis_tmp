# Типы данных и приведение типов 

**Типы данных** - это способ классификации данных, который определяет, какие операции можно выполнять с этими данными и как они хранятся в памяти. Python - это язык с динамической типизацией, это означает, что нам не нужно явно указывать тип переменной при её объявлении. Интерпретатор Python сам определяет тип данных в зависимости от значения, которое вы присваиваете переменной.

## Основные типы данных в Python:

- **Целые числа (int):**  Представляют собой целые числа, например, 10, -5, 0.
- **Вещественные числа (float):** Представляют собой числа с плавающей точкой, например, 3.14, -2.5, 0.0. Обратите внимание, что в качестве разделителя между целой и дробной частью используется точка.
- **Строки (str):**  Представляют собой последовательность символов, заключенных в кавычки (одинарные или двойные), например, "Привет", 'Мир'.
- **Булевы значения (bool):**  Представляют собой логические значения True (истина) или False (ложь).

**Приведение типов** - это процесс преобразования значения одного типа данных в другой.

Для преобразования типов используются следующие функции:

- `int()` — преобразует строку (или вещественное число) в целое число. При конвертации вещественного числа в целое отбрасывается дробная часть;
- `float()` — преобразует строку (или целое число) в вещественное число;
- `str()` — преобразует значения (в общем случае не только числовые) в строки.

К примеру нужно сложить строку и число, Python выдаст ошибку, так как эти операции несовместимы. Чтобы решить эту проблему, нужно привести строку к числу или число к строке.

### Примеры приведения типов:

{% raw %}
```python
a = 5
b = "10"

# Приведение строки к целому числу
c = int(b)
print(a + c)  # Вывод: 15

# Приведение целого числа к строке
d = str(a)
print(d + b) # Вывод: "510"

# Приведение вещественного числа к целому
f = a / 2
print(f) # Вывод: "2.5"
n = int(f)
print(n) # Вывод: "2" ! Дробная часть числа исчезла

# Округление
r = a / 12
print(r)  # Вывод: 0.4166666666666667
print(round(r, 2)) # Вывод: 0.42
print(round(r, 4)) # Вывод: 0.4167
print(round(r, 0)) # Вывод: 0.0

# Приведение целого числа к вещественному
f = float(a)
print(f) # Вывод: "5.0"
```
{% endraw %}

### Важные моменты:

- Не все типы данных можно преобразовать друг в друга. Например, нельзя преобразовать строку, содержащую текст, в число.
- Приведение типов может привести к потере информации. Например, при преобразовании вещественного числа в целое число дробная часть отбрасывается.
