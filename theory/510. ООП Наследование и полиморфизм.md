## Наследование

**Определение**: Наследование — это механизм, позволяющий создавать новый класс на основе существующего, при этом новый класс (дочерний) наследует атрибуты и методы родительского класса.

Создадим простую объектно-ориентированную систему, которая будет моделировать домашних животных. В этой системе мы создадим базовый класс `Animal`, от которого будут наследоваться классы `Dog` и `Cat`.

```
class Dog:
    def __init__(self, name, age, color):
        self.name = name
        self.age = age
        self.color = color

    def say(self):
        print(f"{self.name} говорит: Гав-гав!")

    def info(self):
        print(f"Собака по имени {self.name}, возраст {self.age} лет. Цвет - {self.color}")


class Cat:
    def __init__(self, name, age, color):
        self.name = name
        self.age = age
        self.color = color

    def say(self):
        print(f"{self.name} говорит: Мяу-мяу!")

    def sleep(self):
        print(f"{self.name} спит. Тссс...")        

    def info(self):
        print(f"Кошка по имени {self.name}, возраст {self.age} лет, цвет {self.color}.")
```

Посмотрите на эти два класса. Что у них общее, а что отличается? Оказывается классы очень похожи. Класс `Cat` содержит метод `sleep()` и `info()` немного отличается.

Создадим общий класс `Animal`, а `Dog` и `Cat` унаследуем от него.

```
class Animal:
    def __init__(self, name, age, color):
        self.name = name
        self.age = age
        self.color = color

    def say(self):
        raise NotImplementedError("Этот метод должен быть переопределен в подклассах")

    def info(self):
        print(f"Животное по имени {self.name}. Возраст {self.age} лет. Цвет - {self.color}")


class Dog(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)

    def say(self):
        print(f"{self.name} говорит: Гав-гав!")


class Cat(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)

    def say(self):
        print(f"{self.name} говорит: Мяу-мяу!")

    def sleep(self):
        print(f"{self.name} спит. Тссс...")


if __name__ == "__main__":
    dog = Dog("Шарик", 5, "белый")
    dog.info()
```

В класс `Animal` передаются все данные о животном - возраст, цвет и кличка. Методы также реализованы. Обратите внимание, что `say()` содержит только заглушку. Это может быть полезно, когда придётся реализовывать класс `fish()` или `capibara()`, то есть таких животных, издаваемые звуки которых нам не очеь интересна или неизвестна вовсе.

Метод `info()` реализован полностью, но порял некий *шарм*. Раньше был вывод интереснее - собаку называли собакой, а кошку кошкой. `Animal` *не знает*, о каком животном идёт речь. Можно передать в класс-родитель тип животного, и тогда получится реализовать и метод `say()`, но будет очень громоздко.

Создадим словарь, где ключом будет *type* животного, а значением *- тип* и *речь*.

```
animal_dct = {
    Cat: ('Кошка', 'мяу'),
    Dog: ('Собака', 'гав-гав'),
}
```

Теперь классы животных избавились от метода `say()`. Класс `Animal` стал сложнее, но поставленной задаче отвечает.

```
class Animal:
    def __init__(self, name, age, color):
        self.name = name
        self.age = age
        self.color = color
        self.pet = animal_dct[type(self)]

    def say(self):
        print(f"{self.name} говорит: {self.pet[1].capitalize()}-{self.pet[1]}!")
        # raise NotImplementedError("Этот метод должен быть переопределен в подклассах")

    def info(self):
        print(f"{self.pet[0]} по имени {self.name}. Возраст {self.age} лет. Цвет - {self.color}")


class Dog(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)


class Cat(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)

    def sleep(self):
        print(f"{self.name} спит. Тссс...")


animal_dct = {
    Cat: ("Кошка", "мяу"),
    Dog: ("Собака", "гав"),
}

if __name__ == "__main__":

    dog = Dog("Шарик", 5, "белый")
    dog.info()
    dog.say()

    cat = Cat("Маркиза", 2, "серый")
    cat.info()
    cat.say()
```

При добавлении нового класса животного код сломается. Нужно поддерживать в актуальном состоянии словарь `animal_dct`

```
class Animal:
    def __init__(self, name, age, color):
        self.name = name
        self.age = age
        self.color = color
        self.pet = animal_dct.get(type(self))

    def say(self):
        if self.pet:
            print(f"{self.name} говорит: {self.pet[1].capitalize()}-{self.pet[1]}!")
        else:
            raise NotImplementedError("Этот метод должен быть переопределен в подклассах")

    def info(self):
        if self.pet:
            print(f"{self.pet[0]} по имени {self.name}. Возраст {self.age} лет. Цвет - {self.color}")
        else:
            raise NotImplementedError("Этот метод должен быть переопределен в подклассах")

class Dog(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)


class Cat(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)

    def sleep(self):
        print(f"{self.name} спит. Тссс...")


class Bird(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)


animal_dct = {
    Cat: ("Кошка", "мяу"),
    Dog: ("Собака", "гав"),
}

if __name__ == "__main__":

    dog = Dog("Шарик", 5, "белый")
    dog.info()
    dog.say()

    cat = Cat("Маркиза", 2, "серый")
    cat.info()
    cat.say()

    bird = Bird("Кеша", 3, "белый")
    bird.info()
    bird.say()
```

## Полиморфизм

**Определение**: Полиморфизм — это возможность использования одного интерфейса для работы с разными типами объектов. Это позволяет методам с одинаковыми именами вести себя по-разному в зависимости от объекта, на котором они вызываются.

Cоздадим класс `Owner`, который будет описывать владельца домашних животных.

```
class Animal:
    def __init__(self, name, age, color):
        self.name = name
        self.age = age
        self.color = color
        self.pet = animal_dct.get(type(self))

    def say(self):
        if self.pet:
            return f"{self.name} говорит: {self.pet[1].capitalize()}-{self.pet[1]}!"
        else:
            raise NotImplementedError("Этот метод должен быть переопределен в подклассах")


    def info(self):
        if self.pet:
            return f"{self.pet[0]} по имени {self.name}. Возраст {self.age} лет. Цвет - {self.color}"
        else:
            raise NotImplementedError("Этот метод должен быть переопределен в подклассах")


class Dog(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)


class Cat(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)

    def sleep(self):
        print(f"{self.name} спит. Тссс...")


class Bird(Animal):
    def __init__(self, name, age, color):
        super().__init__(name, age, color)


animal_dct = {
    Cat: ("Кошка", "мяу"),
    Dog: ("Собака", "гав"),
}


class Owner:
    def __init__(self, name):
        self.name = name
        self.pets = []

    def adopt_pet(self, pet):
        """Метод для усыновления домашнего животного."""
        self.pets.append(pet)

    def call_pets(self):
        """Метод для перечисления всех домашних животных."""
        responses = []
        for pet in self.pets:
            responses.append(pet.info())
        return responses

    def make_pets_say(self):
        """Метод для того, чтобы все домашние животные заговорили."""
        sounds = []
        for pet in self.pets:
            sounds.append(pet.say())
        return sounds


if __name__ == "__main__":
    owner = Owner("Иван")

    dog = Dog("Шарик", 5, "белый")
    cat = Cat("Маркиза", 2, "серый")

    owner.adopt_pet(dog)
    owner.adopt_pet(cat)

    print(f"Кто живёт у человека по имени {owner.name}?")
    print("\n".join(owner.call_pets()))
    print()
    print("\n".join(owner.make_pets_say()))
```

Обратите внимание, что в классе `Animal` изменилась реализация `say()` и `info()` - теперь методы молчат, никакого лая или мяуканья, теперь методы молча возвращают строки, а печатать их будем в другом месте.

В теле метода добавлен многострочный комментарий и это не просто так. Теперь этот комментарий будет подсказкой для разработчика. На скриншоте программист написал название метода, навел на него мышь и получил вот такую подсказку.
