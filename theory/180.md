# Логический (булевский) тип данных

`bool` – это тип данных, который может принимать только одно из двух значений:

- **True** (правда):  Это как сказать "да".
- **False** (ложь): Это как сказать "нет".

**Пример:**

- **Вопрос:** "Сегодня солнечно?"
- **Ответ (в bool):**  Если сегодня солнечно, то ответ будет True. Если нет, то False.

## Зачем нужен bool?

`bool` важен для принятия решений в программах и позволяет строить *разветвленные алгоритмы*.

### Примеры использования bool:

```python
age = 16
print(age >= 18)  # Выведет False, потому что 16 < 18


c = 10
print(print % 2)  # Выведет True, потому что 10 делится на 2 без остатка


a = 5
b = 5
print(a == b)  # Выведет True, потому что a и b равны
```

### Командир, который всегда прав

True и False используется в качестве условия if и elif. До недавнего времени мы использовали результат сравнения, который возвращал bool, но можно использовать True без всяких вычислений, напрямую.

```python
if True:
    print('Командир всегда прав')
else:
    print('Командир иногда ошибается')

# Вывод Командир всегда прав
```

Здесь программа всегда будет выводит фразу *Командир всегда прав*, без всяких исключений. Днём и ночью. При каждом запуске программы. Постоянно.
