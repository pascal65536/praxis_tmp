# print()

`print()` печатает параметр в консоль. Функция "всеядна", в качестве параметра (в скобках) мы можем передать что угодно, а функция попытается это напечатать.

```python
print('Python')  # Вывод Python
print(2*3)  # Вывод 6
print(1,2,3,4,5)  # Вывод 1 2 3 4 5
print(print)  # Вывод <built-in function print>
```

Функция напечатала слово Python, результат математической операции, несколько чисел, перечисленных через запятую. Причем на печати запятых нет. И попыталась напечатать служебное слово `print` и мы узнали что это встроенная функция.

```python
print('1', 'два', 3)  # Вывод 1 два 3
```

Здесь функции передали три параметра, перечислив их через запятую.

В Python, **параметр** - это переменная, которая передается в функцию или метод при ее вызове.

Проще говоря: это информация, которую вы "подаете" функции на вход, чтобы она могла выполнить свою задачу.

Парметры могут быть разного типа.

```python
print('P', 'y', 't', 'h', 'o', 'n') # Вывод P y t h o n
```

Мы не можем просто взять и напечатать буквы рядом, почему-то появляются пробелы. Это не простой пробел - это *разделитель*. Мы можем от них избавиться, указав другой разделитель. Разделитель мы тоже подаём на вход функции в качестве параметра, в этот раз именованного. Обратите внимание, что к именованному параметру `sep` функция `print()` относится по-особенному и не печатает его, как остальные параметры.

```python
print('P', 'y', 't', 'h', 'o', 'n', sep='')  # Вывод Python
```

Поиграем с разделителем

```python
print('P', 'y', 't', 'h', 'o', 'n', sep='.')  
# Вывод P.y.t.h.o.n
```

Поробуем разделитель поинтереснее

```print
print('стеклянный', 'оловянный', 'деревянный', sep='; ')
# Вывод стеклянный; оловянный; деревянный
```

Посмотрите, какой разделитель мы запросили - это запятая и пробел. Такое разделитель уместно использовать, если нужно что-то перечислять через запятую, причём в конце перечня запятой не будет.

Как вы поняли, разделителем может быть любая строка.

В Python, как и во многих других языках программирования, есть специальные комбинации символов, называемые *escape-последовательностями*, которые используются для представления непечатаемых символов или для управления форматированием текста.
