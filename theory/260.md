# Словарь (dict)

При работе с данными часто возникает необходимость связывать между собой различные элементы, например, названия стран и их столиц. В таких случаях использование списков с числовыми индексами может быть неудобным и неинтуитивным. В Python существует специальная структура данных, которая позволяет связывать значения с уникальными ключами, — это **словарь** (или `dict` от англ. "dictionary").

Словарь похож на список, но вместо числовых индексов в нем используются ключи, которые могут быть строками, числами или даже кортежами (при условии, что они неизменяемы). Это делает словари идеальными для хранения данных, где каждому ключу соответствует определенное значение.

### Пример использования словаря

Предположим, мы хотим создать программу, которая по названию страны будет выводить название её столицы. Используя словарь, мы можем это сделать следующим образом:

{% raw %}
```python
# Создание словаря, где ключи — названия стран, а значения — названия столиц
countries_and_capitals = {"Россия": "Москва", "США": "Вашингтон", "Франция": "Париж"}

# Вывод названия столицы Франции
print(countries_and_capitals["Франция"])

# Вывод Париж
```
{% endraw %}

Как видно из программы, для создания словаря можно перечислить в фигурных скобках пары: ключ и значение. Ключ и значение отделяются двоеточием и пробелами, а пары перечисляются через запятую.

В качестве ключей можно использовать значения неизменяемого типа: числа, строки, кортежи. Значения по ключу могут быть любого типа данных.

Чтобы взять значение по ключу, необходимо указать ключ в квадратных скобках после имени словаря.

Если же нужно добавить новый ключ в словарь, то его указывают после имени словаря в левой части операции присваивания, а значение, которое будет храниться по этому ключу, — в правой части:

{% raw %}
```python
countries_and_capitals = {"Россия": "Москва", "США": "Вашингтон", "Франция": "Париж"}

countries_and_capitals["Сербия"] = "Белград"

print(countries_and_capitals)
```
{% endraw %}

Обратите внимание, при записи значения по уже существующему ключу он создаётся заново с новым значением, а прошлый стирается:

{% raw %}
```python
d = {"key": "old_value"}

d["key"] = "new_value"

print(d["key"])

# Вывод new_value
```
{% endraw %}

При попытке взять значение по несуществующему ключу происходит исключение KeyError:

{% raw %}
```python
countries_and_capitals = {"Россия": "Москва", "США": "Вашингтон", "Франция": "Париж"}

print(countries_and_capitals["Сербия"])

# Вывод KeyError: 'Сербия'
```
{% endraw %}


Для проверки существования ключа в словаре следует использовать уже известный нам оператор `in`:

{% raw %}
```python
countries_and_capitals = {"Россия": "Москва", "США": "Вашингтон", "Франция": "Париж"}

if "Сербия" in countries_and_capitals:
    print(countries_and_capitals["Сербия"])
else:
    print("Страна пока не добавлена в словарь")
```
{% endraw %}

По ключам в словаре можно пройти в цикле `for`:

{% raw %}
```python
countries_and_capitals = {"Россия": "Москва", "США": "Вашингтон", "Франция": "Париж"}

for country in countries_and_capitals:
    print(f"У страны {country} столица — {countries_and_capitals[country]}.")
    
# Вывод
# У страны Россия столица — Москва.
# У страны США столица — Вашингтон.
# У страны Франция столица — Париж.
```
{% endraw %}


Вспомним, что значением по ключу в словаре может быть значение любого типа. Рассмотрим пример, в котором значением по ключу будет список.

Пусть с клавиатуры вводятся названия стран, каждая с новой строки. При вводе возможны повторы стран. Сигналом окончания ввода будет строка «СТОП». Необходимо вывести, в каких строках (начиная с 0) встречалась каждая из стран. Для решения задачи будем использовать словарь, в котором по ключам — названиям стран будем хранить список номеров строк, в которых эти страны встречались.

{% raw %}
```python
# создаём пустой словарь
countries = dict()
# вводим первую строку до цикла (можно заменить, использовав оператор-морж)
country = input()
# создаём счётчик номеров строк
str_number = 0
# продолжаем цикл, пока не введена строка «СТОП»
while country != "СТОП":
    # если введённой страны нет в словаре, создаём ключ и записываем по ключу список из одного номера строки
    if country not in countries:
        countries[country] = [str_number]
    # иначе добавляем в список по ключу новое значение номера строки
    else:
        countries[country].append(str_number)
    # увеличиваем счётчик
    str_number += 1
    # вводим следующую строку
    country = input()
# выводим название страны и полученные списки с новой строки
for country in countries:
    print(f"{country}: {countries[country]}")


# Пример ввода:
США
США
Россия
Россия
Россия
Франция
Сербия
СТОП

# Вывод
США: [0, 1]
Россия: [2, 3, 4]
Франция: [5]
Сербия: [6]
```
{% endraw %}

Основные операции для словарей перечислены в следующей таблице.

| Операция | Описание | Пример | Вывод |
|---|---|---|---|
| len(d) | Возвращает количество ключей в словаре | d = {"a": 1, "b": 2, "c": 3}<br>print(len(d)) | 3 |
| del d[key] | Удалить ключ из словаря. Если ключа нет, то вызывается исключение KeyError | d = {"a": 1, "b": 2, "c": 3}<br>del d["b"]<br>print(d) | |
| dict.clear() | Удалить все ключи и значения в словаре | d = {"a": 1, "b": 2, "c": 3}<br>d.clear()<br>print(d) | {} |
| dict.copy() | Возвращает копию словаря | d = {"a": 1, "b": 2, "c": 3}<br>d_new = d.copy()<br>print(d_new) | |
| dict.get(key, default) | Возвращает значение по ключу key. Если ключа нет, то возвращает значение default | d = {"a": 1, "b": 2, "c": 3}<br>print(d.get("e", "Ключа нет в словаре")) | Ключа нет в словаре |
| dict.items() | Возвращает итерируемый объект, состоящий из кортежей (ключ, значение) словаря | d = {"a": 1, "b": 2, "c": 3}<br>for key, value in d.items():<br>    print(key, value) | a 1<br>b 2<br>c 3 |
| dict.keys() | Возвращает итерируемый объект, состоящий из ключей словаря | d = {"a": 1, "b": 2, "c": 3}<br>for key in d.keys():<br>    print(key) | a<br>b<br>c |
| d.pop(key, default) | Возвращает значение по ключу key и удаляет его из словаря. Если ключа нет, то возвращает default | d = {"a": 1, "b": 2, "c": 3}<br>x = d.pop("a")<br>print(x) | 1 |
| dict.values() | Возвращает итерируемый объект, состоящий из значений словаря | d = {"a": 1, "b": 2, "c": 3}<br>for value in d.values():<br>    print(value) | 1<br>2<br>3 |
| dict.setdefault(key[, default]) | Возвращает значение ключа, но если его нет, не бросает исключение, а создает ключ со значением default (по умолчанию None). | d = {"a": 1}<br>d.setdefault("b")<br>d.setdefault("c", 3)<br>for value in d.values():<br>    print(value) | 1<br>None<br>3 |
