## Бинарные и унарные операции

Python поддерживает все распространенные арифметические операции.

**Бинарные операции**

```bash
+ Сложение двух чисел

- Вычитание двух чисел

* Умножение двух чисел

/ Деление двух чисел

** Возведение в степень

// Целочисленное деление двух чисел

% Получение остатка от деления
```

Это перечень бинарных операций. Для того, чтобы выполнить такую операцию понадобится 2 числа.

```python
print('13 - 5 = ', 13 - 5)  # Вывод 13 - 5 =  8

print('3 + 5 = ', 3 + 5)  # Вывод 3 + 5 =  8

print('7 * 2 = ', 7 * 2)  # Вывод 7 * 2 =  14

print('16 / 2 = ', 16 / 2)  # Вывод 16 / 2 =  8.0

print('123 // 10 = ', 123 // 10)  # Вывод 123 // 10 =  12

print('123 % 10 = ', 123 % 10)  # Вывод 123 % 10 =  3

print('2 ** 16 = ', 2 ** 16)  # Вывод 2 ** 16 =  65536
```

Теперь попробуем использовать переменные и испытаем *унарную* операцию

```python
alpha = 10
alpha -= 1  # Можно написать alpha = alpha - 1 и результат будет таким же
print(alpha)  # Выведет 9


theta = 3.14
theta *= 2  # Можно написать theta = theta * 2 и результат будет таким же
print(theta)  # Выведет 6.28


gamma = 5
gamma **= 2  # Можно написать gamma = gamma ** 2 и результат будет таким же
gamma(theta)  # Выведет 25
```

Арифметические операции выполняются в порядке приоритета:

1. `**`
2. `*`, `/`, `%`, `//`
3. `+`, `-`

Рассмотрим выражение:

```python
result = 10 + 5 * 2 ** 3 - 4 / 2  # Вывод 48
```

**Решение:**

1. Возведение в степень: `2 ** 3 = 8`
2. Умножение и деление (слева направо): `5 * 8 = 40 и 4 / 2 = 2`
3. Сложение и вычитание (слева направо): `10 + 40 - 2 = 48`

**Результат: 48**
