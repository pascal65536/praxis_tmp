# Шаблоны Jinja2 во Flask

Flask использует Jinja2 для рендеринга HTML-шаблонов. Jinja2 — это мощный и гибкий шаблонизатор, который позволяет динамически генерировать HTML-код, используя данные из вашего приложения Flask.

## Основные концепции:

- **Шаблоны**: Файлы HTML, которые содержат статический контент и специальные теги Jinja2 для вставки динамического контент.
- **Переменные**: Данные, которые передаются из приложения Flask в шаблон.
- **Управляющие структуры**: Условные операторы (if/else) и циклы (for), которые позволяют управлять отображением контента в шаблоне.
- **Фильтры**: Функции, которые применяются к переменным для форматирования или преобразования данных.

```
flask_project/
│
├── templates/
│   └── template.html
│
└── main.py
```

Шаблоны обычно хранятся в папке `templates` в корневой директории вашего приложения Flask.

## Рендеринг шаблона

В функции-обработчике вызывается метод `render_template()` для рендеринга шаблона и передачи ему данных. В качестве аргументов функции передаётся название шаблон и пары "ключ-значение", где ключ — это имя переменной в шаблоне, а значение — данные, которые нужно отобразить в шаблоне.


```python
# main.py

from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def index():
    title = "Моя страница"
    name = "Иван"
    items = ["яблоко", "банан", "груша"]
    return render_template("template.html", title=title, name=name, items=items)

if __name__ == "__main__":
    app.run(debug=True)
    # app.run(host='10.42.0.1', port=5000)
```


Содержимое файла `template.html`:


```html
<!DOCTYPE html>
<html>
<head>
    <title>Мой шаблон</title>
</head>
<body>
    <h1>{{ title }}</h1>
    <p>Привет, {{ name }}!</p>
    <ul>
        {% for item in items %}
            <li>{{ item }}</li>
        {% endfor %}
    </ul>
</body>
</html>
```


В этом примере:


- `{{ title }}` и `{{ name }}` — это переменные, которые будут заменены значениями из приложения Flask.
- `{% for item in items %}` и `{% endfor %}` — это цикл, который выводит список элементов `items`.


## Основные способы разметки данных

### 1. Вывод переменных:


```html
<h1>{{ title }}</h1>
<p>{{ content }}</p>
```


В этом примере `title` и `content` - это переменные, которые передаются в шаблон из функции представления Flask. Двойные фигурные скобки `{{ }}` используются для вывода значения переменной.

### 2. Условные конструкции:


```html
{% if user.is_authenticated %}
    <p>Привет, {{ user.username }}!</p>
{% else %}
    <p>Пожалуйста, войдите в систему.</p>
{% endif %}
```


Здесь используется конструкция `{% if ... %}` для проверки условия. В зависимости от результата проверки, будет выведен соответствующий блок HTML.

### 3. Циклы:


```html
<ul>
    {% for item in items %}
        <li>{{ item }}</li>
    {% endfor %}
</ul>
```



Этот пример демонстрирует цикл `{% for ... %}`, который перебирает элементы списка `items` и выводит каждый элемент в виде элемента списка `<li>`.


Jinja2 также позволяет оперировать отдельными повторениями в цикле с помощью объекта `loop`, у которого доступны свойства:

- `loop.first`: True для первой итерации.
- `loop.last`: True для последней итерации.
- `loop.length`: количество элементов.
- `loop.index`: индекс, начиная с 1.
- `loop.index0`: индекс, начиная с 0.
- `loop.revindex`: количество итераций до конца, начиная с 1.
- `loop.revindex0`: с 0.
- `loop.cycle`: позволяет поочередно брать значения из списка (например, для задания чередующихся CSS-классов строк таблицы).

Пример выделения первого и последнего элемента:


```html
{% for item in items %}
  {% if loop.first %}
    <li>Первый: {{ item }}</li>
  {% elseif loop.last %}
    <li>Последний: {{ item }}</li>
  {% else %}
    <li>{{ item }}</li>
  {% endif %}
{% endfor %}
```


Если нужно получить сам элемент в начале или конце списка, применяйте встроенные фильтры:


- `first()`: возвращает первый элемент коллекции: `{{ data|first }}`
- `last()`: возвращает последний элемент коллекции: `{{ data|last }}`


### 4. Фильтры:


```html
<p>{{ text | safe }}</p>
<p>{{ date | date('Y-m-d') }}</p>
```


Фильтры применяются к переменным с помощью символа `|`. В первом примере `safe` - фильтр, который предотвращает экранирование HTML-кода. Во втором примере `date` - фильтр, который форматирует дату в соответствии с заданным шаблоном.

### 5. Макросы:


```html
{% macro render_item(item) %}
    <div>{{ item.name }}</div>
    <p>{{ item.description }}</p>
{% endmacro %}

{% for item in items %}
    {{ render_item(item) }}
{% endfor %}
```


Макросы позволяют создавать повторно используемые блоки кода. В этом примере макрос `render_item` выводит информацию об элементе `item`.

### 6. Инициализация переменных:

Для задания переменной внутри шаблона используется конструкция `{% set имя = значение %}`. Например, `{% set count = 5%}`. Можно объявлять несколько переменных одновременно: `{% set name, age = 'Tom', 20%}`.

Область видимости зависит от места объявления: внутри блоков (например, циклов или условий) переменная доступна лишь локально. Для сохранения значения переменной после цикла часто используют пространство имён:


```html
{% set ns = namespace(flag=False) %}
{% for el in list %}
  {% if el == "target" %}
    {% set ns.flag = True %}
  {% endif %}
{% endfor %}
{{ ns.flag }}
```


Такая переменная будет доступна и после выхода из цикла.

## Дополнительные возможности Jinja2:

- **Наследование шаблонов**: Позволяет создавать базовые шаблоны, которые наследуются другими шаблонами.
- **Макросы**: Позволяют создавать повторно используемые блоки кода.
- **Фильтры**: Позволяют форматировать и преобразовывать данные, например, `{{ name|capitalize }}` для преобразования имени в верхний регистр.
- **Автоэскейпинг**: Защита от XSS-атак путем автоматического экранирования HTML-тегов в переменных.

# Ссылки в шаблонах Jinja2

В шаблонах Jinja2 Flask вы можете генерировать ссылки с помощью функции `url_for()`. Эта функция генерирует URL для заданной функции представления (view function).

**Пример:**


```html
<a href="{{ url_for('index') }}">Главная страница</a>
<a href="{{ url_for('about') }}">О нас</a>
<a href="{{ url_for('user', username='john_doe') }}">Профиль пользователя</a>
```


**Объяснение:**

- `url_for()` - функция, которая генерирует URL.
- `'index'`, `'about'`, `'user'` - имена функций представлений (view functions), определенных в вашем приложении Flask.
- `username='john_doe'` - аргументы, которые будут переданы функции представления.

**Пример в Python (Flask):**


```python
from flask import Flask, render_template, url_for

app = Flask(__name__)

@app.route('/')
def index():
    return render_template('index.html')

@app.route('/about')
def about():
    return render_template('about.html')

@app.route('/user/<username>')
def user(username):
    return render_template('user.html', username=username)

if __name__ == '__main__':
    app.run(debug=True)
```


**Преимущества использования `url_for()`:**

- **Автоматическое обновление ссылок**: При изменении структуры URL вашего приложения, вам не нужно будет вручную изменять все ссылки в шаблонах.
- **Улучшенная читаемость**: Код шаблонов становится более понятным и легко поддерживаемым.
- **Повышенная безопасность**: Использование `url_for()` помогает избежать уязвимостей, связанных с встраиванием пользовательского ввода в URL.

**Дополнительные возможности:**

- **Передача аргументов**: Вы можете передавать аргументы функции представления через `url_for()`, как показано в примере с `user`.
- **Использование внешних URL**: Вы можете использовать `url_for()` для генерации ссылок на внешние ресурсы, используя параметр `_external=True`.
- **Генерация ссылок с якорями**: Вы можете добавлять якоря к ссылкам, используя параметр `_anchor`.

# Собственные фильтры Jinja2

Собственные фильтры Jinja позволяют расширить функциональность шаблонизатора, добавив кастомные функции для обработки данных. Это полезно, когда стандартных фильтров недостаточно для ваших нужд.

**Пример:**

Предположим, вы хотите создать фильтр, который будет форматировать номер телефона.


```python
def human_format(num):
    num_str = str(num)
    return f'{num_str[0]} ({num_str[1:4]}) {num_str[4:7]}-{num_str[7:9]}-{num_str[9:]}'


app = Flask(__name__)
app.jinja_env.filters.update(human_format = human_format)
```


`template.html`:


```html
Привычный формат: {{ phone | human_format }}
```


**Результат:**

```
Привычный формат: 8 (913) 833-09-22
```

**Объяснение:**

- **Определение фильтра**: Функция `format_price` принимает значение `price` и форматирует его в нужный вид.
- **Регистрация фильтра**: Фильтр регистрируется в окружении Jinja2 с помощью `env.filters['format_price'] = format_price`.
- **Использование фильтра в шаблоне**: В шаблоне фильтр применяется к переменной `price` с помощью синтаксиса `{{ price | format_price }}`.

**Основные моменты:**

- Фильтры - это функции, которые принимают одно значение и возвращают преобразованное значение.
- Фильтры регистрируются в окружении Jinja2 с помощью `env.filters`.
- Фильтры вызываются в шаблонах с помощью синтаксиса `{{ value | filter_name }}`.
- Фильтры могут принимать дополнительные аргументы, которые передаются после названия фильтра через двоеточие.

**Примеры других фильтров:**

Преобразование строки в верхний регистр:


```python
def to_uppercase(s):
  return s.upper()
```


Обрезка строки:


```python
def truncate(s, length):
  return s[:length]
```


Проверка на пустоту:


```python
def is_empty(value):
  return not value
```
