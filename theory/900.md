# 900. HTML

HTML (HyperText Markup Language) — это язык гипертекстовой разметки документов, который используется для создания структуры веб-страниц и отображения их в браузере. Он состоит из множества элементов (тегов), которые сообщают браузеру, как визуально оформить содержимое страницы: заголовки, абзацы, списки, изображения, видео, ссылки и другие компоненты. HTML не является языком программирования, а именно языком разметки для структурирования контента.

Основные моменты про HTML:

- Файлы с кодом HTML обычно имеют расширение .html или .htm.

- Язык был создан Тимом Бернерсом-Ли в 1989 году для обмена научной документацией и стал основой Всемирной паутины.

- Стандартная структура HTML-документа включает теги <html>, <head> и <body>. В <head> размещается служебная информация (например, заголовок страницы и кодировка), а в <body> — содержимое, которое отображается пользователю.

- Теги бывают парными (например, <p></p> для абзацев) и одиночными (например, <img> для изображений).    

- HTML задаёт каркас веб-страницы, а оформление и поведение добавляются с помощью CSS и JavaScript соответственно.
    

Таким образом, HTML — это основа любой веб-страницы, задающая её структуру и связь между элементами контента для браузера, чтобы он мог правильно отображать страницу.

Основные HTML-теги и их назначение:

- <!DOCTYPE> — определяет тип документа, чтобы браузер знал, что это HTML.
- <html> … </html> — корневой тег, контейнер всего содержимого страницы.
- <head> … </head> — содержит метаданные для браузера и поисковиков, например <title>, <meta>, <link>.
- <body> … </body> — содержит видимое содержимое страницы.

Теги для форматирования текста:

- <h1>…<h6> — заголовки разных уровней.
- <p> — абзац текста.
-  <br /> — перенос строки.
- <strong> — выделение важного текста жирным.
- <em> — выделение важного текста курсивом.
    
Теги для списков:
- <ul> — маркированный список.
- <ol> — нумерованный список.
- <li> — элемент списка.

Теги для работы с изображениями и мультимедиа:
- <img> — вставка изображения.
- <audio> — аудиофайл.
- <video> — видеофайл.
    
Теги для ссылок и навигации:
- <a> — гиперссылка.
- <nav> — навигационный блок.

Группировка блоков и структура:
- <div> — блоковый контейнер.
- <span> — строчный контейнер.
- <header>, <footer>, <section>, <article>, <aside> — структурные блоки страницы.

Теги для таблиц:
- <table>, <tr>, <th>, <td> — таблица, строки, заголовки столбцов, ячейки.

Комментарии и скрипты:
- <!-- … --> — комментарии.
- <script> — подключение скриптов.
