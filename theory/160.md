# Условные операторы

Условные операторы – важная часть любого языка программирования. Они позволяют выполнять команды (или наборы команд) только при наличии определённых условий.

При помощи условных операторов программа может определить, выполняются ли определенные условия, а затем решить, что делать дальше.

![Витязь на распутьи](pic/20261012164910.png)

Картина Васнецова "Витязь на распутьи" - яркий пример ветвления.

**К примеру, условные операторы можно было бы использовать в следующих ситуациях:**

- Если студент правильно выполнил как минимум 65% заданий, то он сдал тест; если студент выполнил правильно менее 65% заданий, то он провалил тест.
- Если на счету есть деньги, начисляются проценты; если денег на счету нет, взымается штраф.
- При покупке 10 и больше апельсинов клиенты получают скидку в размере 5%; если они покупают меньше, то не получают скидки.

Оценивая условия и запуская команды в зависимости от соблюдения этих условий, вы можете написать условный код.

## Оператор if

Для начала рассмотрим оператор if. Он определяет условие как истинное или ложное, и если условие истинно, программа выполняет соответствующее действие.

Откройте текстовый редактор и наберите следующие строки:

{% raw %}
```python
age = 10
if age < 14:
    print('Этот фильм нельзя смотреть детям, моложе 14 лет')
```
{% endraw %}

В переменной `age` хранится возрат человека. В данном примере `age=14`

Оператор if сравнивает значение переменной `age` с числом 14 и определяет, может ли человек посетить киносеанс. Если возраст  меньше 14, то проход в кино запрещен. Если условие соблюдено, и значение переменной больше или равно 14, программа выведет на экран «*Этот фильм нельзя смотреть детям, моложе 14 лет*».

Попробуйте увеличить значение переменной `age`:

{% raw %}
```python
age = 20
if age < 14:
    print('Этот фильм нельзя смотреть детям, моложе 14 лет')
```
{% endraw %}

Сохраните и запустите программу. Как видите, теперь значение переменной не отвечает условиям, потому программа ничего не делает.

## Оператор else

В некоторых ситуациях необходимо, чтобы программа выполнила какое-то действие тогда, когда выражение `if` ложно. Для этого используется оператор `else`. Добавьте его в код:

{% raw %}
```python
age = 60
if age < 14:
    print('Этот фильм нельзя смотреть детям, моложе 14 лет')
else:
    print('Просмотр фильма разрешен')
```
{% endraw %}

Итак, значение переменной `age` – целое число 60, что не отвечает условию `age < 14`. Раньше программа просто молчала, теперь благодаря оператору else она может вернуть: `Просмотр фильма разрешен`

Комбинируя операторы if и else, вы можете написать код, который будет выполнять то или иное действие в зависимости от того, истинно или ложно указанное выражение.

## Оператор elif

В некоторых случаях программа должна обрабатывать более двух возможных результатов, чего операторы `if` и `else` обеспечить не могут. В такой ситуации используется оператор `else if`, который в Python сокращен до `elif`. С помощью elif вы можете добавить неограниченное количество дополнительных условий.

Вернёмся к нашей программе. Теперь программа определяет, можно ли человеку совершать восхождение на Эльбрус. Врачи не рекомендут людям старше 60 лет подвергаться серьезным нагрузкам.

{% raw %}
```python
age = input('Ваш возраст')
age = int(age)
if age < 14:
    print('Вы слишком молоды')
elif age > 60:
    print('Вам лучше прогуляться возле дом')
else:
    print('Да, можете попытаться покорить Эльбрус')
```
{% endraw %}

Данная программа выполняет следующие действия:

- Ждет, пока пользователь введёт свой возраст
- Преобразует строку в число. Дальнейшие действия нужно проводить с числами.
- Сравнивает значение переменной `age` с 14, а затем с 60. Если ни одно условие не выполняется, то выводится положительное сообщение.
- Если условие выполняется, то выводится соответствующее сообщение и выполнение оператора `if` прекращается.

Вложенные операторы `if` позволяют добавить в код второстепенные условия, которые будут проверены, если первичное выражение истинно. То есть, таким образом вы можете поместить одно выражение `if-else` внутри другого выражения `if-else`. Синтаксис имеет такой вид:

{% raw %}
```python
age = input('Ваш возраст: ')
age = int(age)
if age < 14:
    print('Вы слишком молоды')
elif age > 60:
    print('Вам лучше прогуляться возле дома. Хотя...')
    training = input('У вас есть соответствующая подготовка, напишите 1-если да и 0-если нет: ')
    training = int(training)
    if training == 1:
        print('Да, вы можете попробовать подняться на Эльбрус.')
    else:
        print('Все-таки вам лучше остаться дома.')
else:
    print('Да, можете попытаться покорить Эльбрус')
```
{% endraw %}

Обратите внимание, что чем глубже вложенность команды, то тем больше отступ. Глубина напрямую влияет на восприятие кода - чем больше отступов, тем сложнее читать код - программисту нужно помнить, почему мы находимся именно в этой ветке. Для строк с отступами может не хватить символов - внезапно программист "упрётся" в предел - 80 символов в строке, потому что первые 8 или 16 символов - просто пробелы.

Вложенные операторы `if` позволяют создать несколько дополнительных уровней кода и расширить его функции.

В качестве условия может выступать результат операции сравнения:

- `>` (больше);
- `>=` (больше или равно);
- `<` (меньше);
- `<=` (меньше или равно);
- `==` (равно);
- `!=` (не равно).

Для записи сложных условий можно применять логические операции:

- `and` — логическое «И» для двух условий. Возвращает `True`, если оба условия истинны, иначе возвращает `False`;
- `or` — логическое «ИЛИ» для двух условий. Возвращает `False`, если оба условия ложны, иначе возвращает `True`;
- `not` — логическое «НЕ» для одного условия. Возвращает `False` для истинного условия, и наоборот.

Ниже приведена таблица истинности для логических операций.

| x | y | not x | x or y | x and y |
|---|---|---|---|---|
| False | False | True | False | False |
| False | True | True | True | False |
| True | False | False | True | False |
| True | True | False | True | True |

Рассмотрим следующий пример:

{% raw %}
```python
service = input('Автомобиль исправлен? 0 - нет, 1 - да: ')
fuel = input('Топливный бак заправлен? 0 - нет, 1 - да: ')

if service == '1' and fuel == '1':
    print('Вы можете отправиться в путешествие на машине.')
else:
    print('Почините машину и заправьте её.')
```
{% endraw %}

Мы можем отправиться в путешествие на автомобиле при соблюдении двух условий: машина исправна **И** бак полон.

**Рассмотрим ещё один пример:**

Оптимальная температура воздуха для катания на коньках считается диапазон от -5 до -12°, а если нет ветра, то и до -15°.

{% raw %}
```python
temperatura = int(input("Ввежите температуру воздуха: "))
veter = int(input("Ветер на улице сильный? 0 - нет, 1 - да: "))

if (veter == 0 and temperatura >= -15 and temperatura <= -5) or (
    veter == 1 and temperatura >= -12 and temperatura <= -5
):
    print("Погода комфортная для катания!")
else:
    print("Погода не комфортная для катания!")
```
{% endraw %}

Здесь сложная конструкция, которая не вошла в одну строку в точности повторяет утверждение врачей. Понятное человеку становится сложно для программиста. Попробуем модифицировать код, так, чтобы он стал проще.

{% raw %}
```python
temperatura = int(input('Ввежите температуру воздуха: '))
veter = int(input('Ветер на улице есть? 0 - нет, 1 - да: '))

if veter == 0 and temperatura >= -15 and temperatura <= -5:
    print("Погода комфортная для катания!")
elif veter == 1 and temperatura >= -12 and temperatura <= -5:
    print("Погода комфортная для катания!")
else:
    print("Погода не комфортная для катания!")
```
{% endraw %}

Так стало значительно понятнее. Обратите внимание, что `elif` выполняет роль `or`.

Будем исключать неподходящие варианты по очереди:

{% raw %}
```python
temperatura = int(input("Ввежите температуру воздуха: "))
veter = int(input("Ветер на улице сильный? 0 - нет, 1 - да: "))

if temperatura > -5:
    print("Погода не комфортная для катания!")
elif temperatura < -15:
    print("Погода не комфортная для катания!")
elif veter == 0 and temperatura < -12:
    print("Погода не комфортная для катания!")
elif veter == 1 and temperatura < -15:
    print("Погода не комфортная для катания!")
else:
    print("Погода комфортная для катания!")
```
{% endraw %}

Если на улице теплее -5, то нет смысла узнавать, есть ли ветер. Если на улице холоднее -15, то на катке явно будет не комфортно. Так как мы избавились от крайних значений, то осталось уточнить двумя короткими сравнениями температуру и ветер.

Такой способ называется **безопасный if**. Его легко отлаживать и читать. Он позволяет избавиться от неподходящих вариантов на ранних этапах.

## Логический (булевский) тип данных

`bool` – это тип данных, который может принимать только одно из двух значений:

- **True** (правда):  Это как сказать "да".
- **False** (ложь): Это как сказать "нет".

**Пример:**

- **Вопрос:** "Сегодня солнечно?"
- **Ответ (в bool):**  Если сегодня солнечно, то ответ будет True. Если нет, то False.

### Зачем нужен bool?

`bool` важен для принятия решений в программах и позволяет строить *разветвленные алгоритмы*.

**Примеры использования bool:**

```
age = 16
print(age >= 18)  # Выведет False, потому что 16 < 18


c = 10
print(print % 2)  # Выведет True, потому что 10 делится на 2 без остатка


a = 5
b = 5
print(a == b)  # Выведет True, потому что a и b равны
```

### Командир, который всегда прав

True и False используется в качестве условия if и elif. До недавнего времени мы использовали результат сравнения, который возвращал bool, но можно использовать True без всяких вычислений, напрямую.

{% raw %}
```python
if True:
    print('Командир всегда прав')
else:
    print('Командир иногда ошибается')

# Вывод Командир всегда прав
```
{% endraw %}

Здесь программа всегда будет выводит фразу *Командир всегда прав*, без всяких исключений. Днём и ночью. При каждом запуске программы. Постоянно.
