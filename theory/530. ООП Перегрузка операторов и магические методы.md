## Перегрузка операторов и магические методы

В объектно-ориентированном программировании на Python можно перегружать стандартные операторы и методы, используя специальные методы (*или магические методы*, *double underline*, *dunder*). Эти методы позволяют определить, как объекты вашего класса должны вести себя при использовании стандартных операторов, таких как сложение, сравнение и так далее. Давайте рассмотрим несколько из них.

## Перегрузка оператора сравнения (*\_\_eq\_\_, \_\_lt\_\_*, и т.д.)

Вы можете перегрузить операторы сравнения, такие как  \==, \>=, \> , и т.д., реализуя соответствующие методы.

```python
class Figure():
    def __init__(self, width=None, height=None):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height
    
    def perimeter(self):
        return 2 * (self.width + self.height)

    def __lt__(self, other):
        return self.area() < other.area()

    def __le__(self, other):
        return self.area() <= other.area()

    def __eq__(self, other):
        return self.area() == other.area()

    def __ne__(self, other):
        return self.area() != other.area()

    def __gt__(self, other):
        return self.area() > other.area()

    def __ge__(self, other):
        return self.area() >= other.area()
    
    def __str__(self):
        return f"Фигура со сторонами {self.width} и {self.height}"
    
    def __repr__(self):
        return f"Figure({self.width}, {self.height})"

class Rectangle(Figure):
    ...

class Square(Figure):
    ...


if __name__ == '__main__':
    rectangle = Rectangle(4, 6)
    square = Square(4)

    print(f"Площадь прямоугольника: {rectangle.area()}")
    print(f"Площадь квадрата: {square.area()}")

    # Сравнение фигур
    if rectangle > square:
        print("Прямоугольник больше квадрата")
    else:
        print("Прямоугольник меньше или равен квадрату")
```

## Перегрузка оператора сложения (*\_\_add\_\_*)

Чтобы определить, как объекты вашего класса будут реагировать на оператор  + , вы можете реализовать метод *__add__*.

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(2, 3)
v2 = Vector(4, 5)
v3 = v1 + v2
print(v3)  # Вывод: Vector(6, 8)
```

## Перегрузка оператора вычитания (*\_\_sub\_\_*)

Аналогично оператору сложения, вы можете перегрузить оператор вычитания  -  с помощью метода *\_\_sub\_\_*.

```python
class Figure():
    def __init__(self, width=None, height=None):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height
    
    def perimeter(self):
        return 2 * (self.width + self.height)
    
    def __sub__(self, other):
        if isinstance(other, (Figure, Rectangle, Square)):
            return self.area() - other.area()
        raise TypeError("Вычитание только из фигуры")


class Rectangle(Figure):
    ...

class Square(Figure):
    ...


if __name__ == '__main__':
    rectangle = Rectangle(1, 1)
    square = Square(10)

    new_figure_area = square - rectangle
    print(rectangle.area())  # Вывод 1
    print(square.area())  # Вывод 100
    print(new_figure_area)  # Вывод 99
```

## Перегрузка оператора умножения (*\_\_mul\_\_*)

Перегрузка оператора умножения позволяет определить поведение при использовании оператора  * .

```python
class Figure():
    def __init__(self, width=None, height=None):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height
    
    def perimeter(self):
        return 2 * (self.width + self.height)
    
    def __mul__(self, other):
        if isinstance(other, (int, float)):
            return Figure((self.width * other ** 0.5), (self.height * other ** 0.5))
        raise TypeError("Умножение только на числа")


class Rectangle(Figure):
    ...

class Square(Figure):
    ...


if __name__ == '__main__':
    rectangle = Rectangle(4, 6)
    new_rectangle = (rectangle * 2) 
    print(rectangle.area())  # Вывод 24
    print(new_rectangle.area())  # Вывод 48.00000000000001

    square = Square(10)
    new_square = (square * 0.1)
    print(square.area())  # Вывод 100
    print(new_square.area())  # Вывод 10.000000000000002
```

## Перегрузка строкового представления (*\_\_str\_\_ и \_\_repr\_\_*)

Методы `__str__` и `__repr__` используются для определения строкового представления объектов вашего класса.

```python
class Figure():
    def __init__(self, width=None, height=None):
        self.width = width
        self.height = height

    def __str__(self):
        return f"Фигура со сторонами {self.width} и {self.height}"
    
    def __repr__(self):
        return f"Figure({self.width}, {self.height})"


if __name__ == '__main__':
    figure = Figure(1, 1)
    print(figure)  # Вывод Фигура со сторонами 1 и 1
    print(f'{figure}')  # Вывод Фигура со сторонами 1 и 1
```

## Заключение

Перегрузка стандартных операторов и методов в Python позволяет создавать более интуитивно понятные и удобные для использования классы. Это делает код более читаемым и позволяет использовать стандартные операции с пользовательскими объектами так же, как с встроенными типами данных.
