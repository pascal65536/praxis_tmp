# Проверка решения

1. Скачайте файлы `student.py`, `check.py` и `check.json` и сохраните их в одной папке.
2. Напишите своё решение в файле `student.py`. Реализуйте функцию `solve(data)`, которая принимает строку в формате `author_id|message` и возвращает список `[статус, причина]`. Не изменяйте имя файла и сигнатуру функции.
3. Файл `check.json` содержит тестовые данные и ожидаемые результаты. Не изменяйте его, а также файл `check.py`.
4. Откройте терминал в папке с файлами и запустите проверку:


```bash
python3 check.py
```


Если команда `python3` недоступна, используйте:


```bash
python check.py
```


5. После завершения проверки на экран будет выведено количество пройденных и непройденных тестов. Для непройденных тестов программа покажет входные данные, ожидаемый и полученный результаты.
