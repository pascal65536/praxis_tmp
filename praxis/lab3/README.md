## Проверка решения

1. Скачайте `student.py`, `check.py`, `check.json`, `expected_sample.json` и `data/sample.log`, сохранив структуру папок.
2. Напишите решение в `student.py` по постановке из [index.md](index.md). Не изменяйте имя файла и сигнатуры функций.
3. Для отладки используйте только `data/sample.log`: он содержит все разновидности строк полного журнала. Файл `vkbot.log` нужен только преподавателю для итоговой проверки и студенту не выдаётся.
4. Не изменяйте `check.py`, `check.json`, `expected_sample.json` и `data/sample.log`.
5. Откройте терминал в папке с файлами и запустите проверку обязательной части:

```bash
python3 check.py
```

Если команда `python3` недоступна, используйте `python check.py`. На Windows можно также использовать `py -3 check.py`.

6. Для проверки обязательной и дополнительных частей выполните:

```bash
python3 check.py --advanced
```

7. После завершения будет выведено количество пройденных проверок и диагностика ошибок. Полный результат — **7 из 7** в базовом режиме и **12 из 12** в расширенном. Внешние библиотеки устанавливать не требуется.
