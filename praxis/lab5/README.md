1. Скачайте файлы с раширениями *.txt и *.py
2. Полностью скопируйте содержимое файла templates.py в файл server.py.
3. Файл requirements.txt содержит необходимые пакеты для запуска сервера.
4. Создайте виртуальное окружение и установите пакеты из файла requirements.txt.
5. После внесения изменений перезапускайте сервер.
6. Запускайте check.py, чтобы проверить правильность вашего решения.
