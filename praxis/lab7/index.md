# Лабораторная работа №7. Flask приложение для регистрации пользователей от имени администратора

Разработать Flask приложение, позволяющее авторизованному пользователю создавать учетные записи для других пользователей.

## Функциональные требования:

- Приложение должно предлагать пользователю авторизоваться на сайте.
- Для авторизованного пользователя открывать страницу для создания учетных записей других пользователей.
- Хранить данные в едином JSON-файле. Другие файлы не использовать.
- Хранить пароли в открытом виде запрещено.
- Не допускать регистрации пользователя с плохим паролем.
- Не допускать регистрации пользователей с одинаковыми username.
- Сохранять в JSON-файле дату регистрации и дату последней авторизации.
- Обязательно используйте Формы Flask.
