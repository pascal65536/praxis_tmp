# Лабораторная работа №8. Flask приложение для создания постов в блоге

Разработать Flask + SQLAlchemy приложение, позволяющее авторизованным пользователям создавать новые посты в блоге. У каждой записи должен быть автор, категория и теги. Ра

## Функциональные требования:

- Приложение должно предлагать пользователю авторизоваться на сайте.
- Для авторизованного пользователя открывать страницу для CRUD поста, категории и тегов.
- Посты можно фильтровать по категории, автору или тегу.
- Авторизованный пользователь видит новостей больше, чем анонимный пользователь. От анонимных пользователей скрыты записи с отметкой `is_private`.
- Хранить данные в БД SQLite.

\* Дополнительно реализовать дамп записей и импорт из дампа
