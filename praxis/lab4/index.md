## Задача 1. Инкапсуляция: «Умный кошелёк»

Создайте класс `Wallet`.

1. Конструктор `__init__(self, initial_balance)` принимает начальный баланс. Если передано отрицательное число, баланс должен стать `0`.
2. Баланс хранится в защищённом атрибуте `_balance`.
3. Метод `deposit(amount)` пополняет счёт. Если `amount <= 0`, метод не изменяет баланс и возвращает `False`. При успешном пополнении возвращает `True`.
4. Метод `withdraw(amount)` снимает средства. Если `amount <= 0` или средств недостаточно, метод не изменяет баланс и возвращает `False`. При успешном снятии возвращает `True`.
5. Метод `get_balance()` возвращает текущее численное значение баланса.

Снятие всей доступной суммы разрешено. Проверку нечисловых аргументов выполнять не требуется.

### Пример

```python
wallet = Wallet(100)

print(wallet.deposit(50))       # True
print(wallet.withdraw(30))      # True
print(wallet.withdraw(200))     # False
print(wallet.get_balance())     # 120
print(wallet._balance)          # 120
```

Защищённый атрибут `_balance` — это соглашение об инкапсуляции, а не запрет языка на доступ к атрибуту.

## Задача 2. Полиморфизм: «Склад фигур»

Реализуйте классы `Triangle` и `Circle`.

### `Triangle`

- Конструктор `Triangle(a, b, c)` сохраняет три стороны.
- Метод `perimeter()` возвращает сумму сторон.

### `Circle`

- Конструктор `Circle(r)` сохраняет радиус.
- Метод `perimeter()` возвращает длину окружности по формуле `2 * math.pi * r`.

Напишите функцию:

```python
def calculate_total_perimeter(shapes):
    ...
```

Функция принимает список фигур и возвращает сумму результатов вызова `perimeter()` для каждого объекта. Для пустого списка результат равен `0`.

Функция не должна использовать `isinstance()` или `type()` для определения вида фигуры. Она должна работать с любыми объектами, у которых есть подходящий метод `perimeter()`.

В тестах стороны треугольника и радиус являются корректными положительными числами. Отдельная валидация фигур не требуется.

### Пример

```python
shapes = [Triangle(3, 4, 5), Circle(10)]
total = calculate_total_perimeter(shapes)

print(total)  # 74.83185307179586
```

## Задача 3. Операции с векторами в двумерном пространстве

Создайте класс `Vector2D` с числовыми атрибутами `x` и `y`.

Переопределите следующие методы:

1. `__add__(self, other)` — возвращает **новый** вектор, являющийся суммой двух векторов.
2. `__mul__(self, other)` — если второй операнд является числом `int` или `float`, возвращает **новый** вектор, умноженный на это число.
3. `__eq__(self, other)` — векторы равны, если равны их координаты `x` и `y`.
4. `__str__(self)` — возвращает строку вида `"(x, y)"`, например `"(3, 4)"`.
5. `__hash__(self)` — возвращает хеш, согласованный с `__eq__`: если `v1 == v2`, то `hash(v1) == hash(v2)`.

Векторы должны быть пригодны для использования в `set` и в качестве ключей `dict`.

### Требования к обработке типов

- В `__add__` возвращайте `NotImplemented`, если `other` не является `Vector2D`.
- В `__mul__` возвращайте `NotImplemented`, если `other` не является `int` или `float`.
- В `__eq__` возвращайте `NotImplemented`, если `other` не является `Vector2D`.

Благодаря `NotImplemented` Python корректно сформирует результат сравнения или ошибку `TypeError` для неподдерживаемой операции.

Операции `+` и `*` не должны изменять исходные векторы. Обратная операция `3 * vector` в этой работе не требуется.

В рамках работы вектор считается неизменяемым после создания: не присваивайте новые значения его координатам. Это особенно важно после помещения вектора в `set` или использования в качестве ключа `dict`.

### Пример

```python
v1 = Vector2D(1, 2)
v2 = Vector2D(3, 4)

print(v1 + v2)          # (4, 6)
print(v1 * 3)           # (3, 6)
print(v1 == Vector2D(1, 2))  # True
print({v1, Vector2D(1, 2)})  # один элемент
```

## Задача 4. Наследование: «Сотрудники и менеджеры»

Базовый класс уже приведён в шаблоне:

```python
class Employee:
    def __init__(self, name, base_salary):
        self.name = name
        self.base_salary = base_salary

    def calculate_bonus(self):
        return self.base_salary * 0.10
```

Создайте класс `Manager`, который наследуется от `Employee`.

1. Конструктор `Manager(name, base_salary, team_size)` принимает имя, базовую зарплату и размер команды.
2. Используйте `super()` для инициализации атрибутов базового класса.
3. Сохраните размер команды в атрибуте `team_size`.
4. Переопределите `calculate_bonus()`: бонус менеджера составляет 10 % базовой зарплаты плюс 5 % базовой зарплаты за каждого члена команды.

Формула:

```python
base_salary * 0.10 + base_salary * 0.05 * team_size
```

### Пример

```python
manager = Manager("Alice", 50000, 5)

print(manager.calculate_bonus())  # 17500.0
print(isinstance(manager, Employee))  # True
```
