## О курсе

Курс посвящён программированию для специалистов в области информационной безопасности. Он начинается с основ Python и не предполагает одинакового уровня подготовки у всех студентов.

Первый блок позволяет выровнять базовые навыки. Общей контрольной точкой является объектно-ориентированное программирование: после него студенты должны уметь самостоятельно разрабатывать, запускать и проверять небольшие программы. Второй блок посвящён HTTP, REST API и разработке веб-приложений на Flask, включая шаблоны, формы, HTML, Bootstrap и развёртывание проекта.

Примеры и задания постепенно связываются с профессиональными задачами: обработкой журналов событий, сетевых данных и JSON, извлечением признаков из текстов, взаимодействием с API и автоматизацией рутинных операций. Курс не является курсом по безопасной разработке или статическому анализу уязвимостей.
