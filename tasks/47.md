## Задача 1

Вводятся три строки. Написать программу, которая выводит символы, которые есть в трех строках сразу. Из полученных символов создать строку и отсортировать её по алфавиту. В качестве разделителя используйте пробел.

### Примеры

**Пример 1**

Ввод:
```
hello
world
python
```

Вывод:
```
o
```

**Пример 2**

Ввод:
```
apple
people
pleat
```

Вывод:
```
e l p
```

**Пример 3**

Ввод:
```
mathematics
chemistry
physics
```

Вывод:
```
c h i s
```

**Пример 4**

Ввод:
```
12345
54321
13579
```

Вывод:
```
1 3 5
```

**Пример 5**

Ввод:
```
programming
development
deployment
```

Вывод:
```
m n o p
```

**Пример 6**

Ввод:
```
abcdef
bcdefg
cdefgh
```

Вывод:
```
c d e f
```
