# Задача 01. Скажи миру "Привет!"

На вход функции поступает строка — имя человека. Нужно написать функцию, которая здоровается. Функция должна возвращать строку "Привет, <имя>!"

## Задание

Реализуйте в файле `student.py` функцию:

```python
def solve(data):
    ...
```


## Примеры

| Вход | Результат |
| --- | --- |
| `Иван` | `Привет, Иван!` |
| `Сергей` | `Привет, Сергей!` |
| `Мария` | `Привет, Мария!` |
| `Анна` | `Привет, Анна!` |

## Проверяющая система

Проверяющая система использует файл `check.json`. Каждый тест имеет следующую структуру:

```json
{
    "id": 1,
    "input": "Иван",
    "output": "Привет, Иван!"
},
```

Для каждого теста система вызывает `solve(input)` и сравнивает полученный результат с `output`.

Инструкция по запуску находится в файле `README.md`.
