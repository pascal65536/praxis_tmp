## Задача 2

Разработайте функцию `modern_print()`, которая принимает строку и выводит её, если она не была выведена ранее.

*PS. В качестве одного из примеров использованы строки из песни гр. ДДТ "Периферия".*

### Примеры

**Пример 1**

Ввод (код):

```
modern_print("Hello")  # Выведет: Hello
modern_print("World")  # Выведет: World
modern_print("Hello")  # Ничего не выведет, так как "Hello" уже было выведено
modern_print("Python") # Выведет: Python
modern_print("World")  # Ничего не выведет, так как "World" уже было выведено
```

Вывод:

```
Hello
World
Python
```
