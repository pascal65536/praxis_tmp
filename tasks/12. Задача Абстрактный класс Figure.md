
## Задача: Абстрактный класс Figure

Создайте абстрактный класс ***Figure***, который будет служить базовым для других фигур. Реализуйте методы *\_\_str\_\_(self) и \_\_repr\_\_(self)* в базовом классе.

Унаследуйте классы ***Square*** и ***Rectangle*** так, чтобы избавить их от методов *area(self)* и *perimeter(self)*, а все расчеты передать базовому классу. Методы *\_\_str\_\_(self) и \_\_repr\_\_(self)* переопределите.

### Примеры

**Пример 1**

Ввод (код):

```
rectangle = Rectangle(3, 4)
square = Square(5)
figure = Figure(13, 14)
print(rectangle) 
print(square)  
print(figure)  
```

Вывод:

```
Прямоугольник со сторонами 3 и 4
Квадрат со стороной 5
Фигура со сторонами 13 и 14
```

**Пример 2**

Ввод (код):

```
print(Rectangle(3, 4)) 
print(Square(5))  
print(Figure(13, 14))  
```

Вывод:

```
Прямоугольник со сторонами 3 и 4
Квадрат со стороной 5
Фигура со сторонами 13 и 14
```

**Пример 3**

Ввод (код):

```
print(Rectangle(3, 4).area()) 
print(Square(5).area())  
print(Figure(13, 14).area())  
```

Вывод:

```
12
25
182
```

**Пример 4**

Ввод (код):

```
print(Rectangle(13, 24).perimeter() + Square(35).perimeter() + Figure(43, 54).perimeter())  
```

Вывод:

```
408
```
