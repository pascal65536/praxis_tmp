## Примеры

| Вход | Результат |
| --- | --- |
| `10|2` | `1010` |
| `65535|16` | `FFFF` |

## Проверяющая система

Проверяющая система использует файл `check.json`. Каждый тест имеет следующую структуру:

```json
{
    "id": 1,
    "input": "10|2",
    "output": "1010"
},
```

Для каждого теста система вызывает `solve(input)` и сравнивает полученный результат с `output`.

Инструкция по запуску находится в файле `README.md`.
