# Задача 40. API студентов: фильтрация, сортировка, пагинация

Дан файл `students.json` — список студентов вида
`{"full_name": str, "grades": list[int], "missed_classes": int}`.
Требуется реализовать функцию `solve`, которая по параметрам фильтрации,
сортировки и пагинации возвращает отфильтрованный/отсортированный/обрезанный
список студентов.

## Задание

Реализуйте в файле `student.py` функцию:

```python
def solve(sort=None, order="asc", filter=None,
          min_avg=None, max_missed=None, limit=5, offset=0):
    ...
```

### Параметры

- `sort` — поле сортировки: `None`, `"name"`, `"avg"`, `"missed"`;
- `order` — направление: `"asc"` (по умолчанию) или `"desc"`;
- `filter` — подстрока для поиска по `full_name` (регистронезависимо);
- `min_avg` — минимальный средний балл (включительно);
- `max_missed` — максимальное число пропусков (включительно);
- `limit` — сколько записей вернуть (по умолчанию `5`);
- `offset` — сколько записей пропустить (по умолчанию `0`).

### Поведение

1. Читает `students.json` (UTF-8).
2. **Фильтрация** (в любом порядке, результаты пересекаются):
   - `filter` — `filter.lower() in full_name.lower()`;
   - `min_avg` — средний балл студента `>= min_avg`;
   - `max_missed` — `missed_classes <= max_missed`.
3. **Сортировка** по `sort`:
   - `"name"` → по `full_name`;
   - `"avg"` → по среднему баллу;
   - `"missed"` → по `missed_classes`;
   - `order="desc"` — обратный порядок.
4. **Пагинация**: `result[offset:offset + limit]` (при `limit=None` — до конца).
5. Возвращает список словарей **без** вспомогательного поля `avg`
   (в исходном формате: `full_name`, `grades`, `missed_classes`).

Средний балл считается как `sum(grades) / len(grades)`.

## Примеры

| Вызов | Результат |
| ----- | --------- |
| `solve()` | первые 5 студентов из `students.json` |
| `solve(sort="name", order="asc")` | все, отсортированы по ФИО по возрастанию (с пагинацией по умолчанию) |
| `solve(filter="Иванов")` | только `Иванов Иван Иванович` |
| `solve(filter="ова")` | все, в ФИО которых есть «ова» (Сидорова, Смирнова, …) |
| `solve(min_avg=4.5)` | студенты со средним баллом ≥ 4.5 |
| `solve(max_missed=2)` | студенты с пропусками ≤ 2 |
| `solve(limit=2, offset=20)` | 2 записи начиная с 21-й |
| `solve(filter="ова", sort="name")` | отфильтровано по «ова» и отсортировано по ФИО |

## Проверяющая система

Проверяющая система использует `check.json`. Каждый тест имеет структуру:

```json
{
    "id": 1,
    "description": "GET /students - получить весь список",
    "setup": "i1.py",
    "expected_file": "o1.py"
}
```

- `setup` — файл, который выполняется после `student.py` и должен определить `ret`
  (например, `ret = solve(limit=6, offset=10)`);
- `expected_file` — файл с ожидаемым значением `ret` (Python- или JSON-литерал).

Для каждого теста система:

1. внедряет код `student.py` в чистое пространство имён;
2. выполняет `setup`-файл;
3. читает ожидаемое значение из `expected_file`;
4. сравнивает `ret` с эталоном (float — с допуском `1e-9`).
