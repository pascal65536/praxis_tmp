## Задача 1

Пользователь вводит с клавиатуры фамилии учеников и их оценки по программированию через пробел. Ввод продолжается до тех пор, пока не будет введена пуста строка.

Напишите программу, которая составляет словарь, где ключ - оценка по программированию, значение - список учеников, получивших эту оценку.

Ученики в списке должны располагаться в алфавитном порядке. Не может быть двух одинаковых фамилий учеников.

Напечатайте словарь с оценками пользователей.

### Примеры

**Пример 1**

Ввод:

```
Иванов 5
Сергеев 4
Семёнов 3
```

Вывод:

```python
{'5': ['Иванов'], '4': ['Сергеев'], '3': ['Семёнов']}
```
