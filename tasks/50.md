# Калькулятор

Написать Flask-приложение "Калькулятор". В адресной строке GET-параметрами передаются аргументы и операнд. Вычислить значение и вернуть его в браузер пользователю.

Для операции сложения будем использовать значение "add", умножение - "mult", разность - "diff", деление - "sub".

Пример:

http://127.0.0.1:5000/calc?a=10&b=12&op=add
