# Задача 29. Успеваемость учеников

В школе ведётся учёт оценок учеников по нескольким предметам. Необходимо определить предмет с наихудшей успеваемостью и отсортировать учеников по убыванию их среднего балла.

## Задание

Реализуйте в файле `student.py` функцию:

```python
def solve(data):
    ...
```

Функция принимает один аргумент `data` — строку, в которой строки ввода объединены символом `|`.

Первая строка имеет формат:
```
<название предмета> <количество учеников>
```

Далее следуют строки вида:
```
<фамилия> <оценка>
```

После оценок по одному предмету идёт строка со следующим предметом и количеством учеников. Ввод заканчивается, когда все данные прочитаны.

Например:
```
Программирование 3|Иванов 5|Сергеев 4|Семёнов 3|Математика 4|Иванов 5|Сергеев 4|Семёнов 3|Антонов 2
```

Внутри функции необходимо разделить входную строку по символу `|`:
```python
lines = data.split("|")
```

Функция должна возвращать строку, содержащую:
1. Название предмета с наихудшей успеваемостью.
2. Список фамилий учеников, отсортированных по убыванию среднего балла, разделённых пробелом.

Результат возвращается в виде одной строки, где предмет и список учеников разделены символом `|`:
```
"Программирование|Иванов Сергеев Семёнов Петров Антонов Панов"
```

## Уточнения

- Если ученик не получил оценку по какому-либо предмету, считается, что он получил `0`.
- При равенстве средних баллов сортировка по фамилии идёт **обратно алфавитному порядку** (то есть от "Я" до "А").

## Проверяющая система

Проверяющая система использует файл `check.json`. Каждый тест имеет следующую структуру:

```json
{
    "id": 1,
    "input": "Программирование 3|Иванов 5|Сергеев 4|...",
    "output": "Программирование|Иванов Сергеев Семёнов Петров Антонов Панов"
}
```

Для каждого теста система вызывает `solve(input)` и сравнивает полученный результат с `output`.

Инструкция по запуску находится в файле `README.md`.
