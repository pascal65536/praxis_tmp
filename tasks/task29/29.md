## Задача 4

Пользователь вводит с клавиатуры название предмета и количество учеников, затем следует ввод фамилий учеников и их оценки по указанному предмету через пробел. Ввод продолжается до тех пор, пока не будет введена пустая строка.

Выведите на печать название предмета с наихудшей успеваемостью по среднему баллу.

Выведите на печать список учеников расположенных по ухудшению успеваемости. Если у учеников совпадает средний балл, то таких учеников следует располагать в обратном лексикографическом порядке = отсортировать фамилии в обратном алфавитном порядке.

NB: Если ученик не получил оценку по какому-либо предмету, то считается, что он получил 0.

**Пример 1**

Ввод:

```

Сергеев 4
Семёнов 3

Черчение 6
Сергеев 4
Семёнов 3
Антонов 2
Петров 4
Иванов 5
Панов 2
```

Вывод:

```
Программирование
Иванов Сергеев Семёнов Петров Антонов Панов
```
