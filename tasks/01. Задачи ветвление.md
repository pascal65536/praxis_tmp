Вводятся три числа: **a**, **b**, **c**. Определить, могут ли они быть сторонами треугольника. Вывести сообщение "_Треугольник построить можно_" если треугольник возможен и "_Треугольник построить нельзя_", если треугольник построить нельзя.

Условия существования треугольника: **а<b+с**; **b<a+c**; **c<a+b**. Нельзя исключать экстремальных случаев, когда одна (или несколько) сторон равны нулю либо когда одно из неравенств переходит в равенство (треугольник нулевой площади).

**Важно:** Длина отрезка не может быть отрицательной

![](https://ucarecdn.com/9f109451-ecff-48c5-854d-7798972a9f65/)

```python
a = float(input())
b = float(input())
c = float(input())
ma = max([a, b, c ])
if ma < sum([a, b, c]) - ma:
    print("Треугольник построить можно")
else:
    print("Треугольник построить нельзя")
```

14.
**Задача:** Напишите программу, которая проверяет, является ли трехзначное число "красивым".

**Что такое "красивое" число?**

Трехзначное число считается "красивым", если сумма его наибольшей и наименьшей цифр равна удвоенной средней цифре.

**Например:**

- Число 123 - красивое, потому что 1 + 3 = 2 * 2
- Число 541 - не красивое, потому что 5 + 1 != 2 * 4

Вводится трехзначное число. Нужно разбить число на цифры. Найти наибольшую, наименьшую и среднюю цифры. Вычислить "красоту числа". Вывести "YES", если число красивое, и "NO" в противном случае.

```python
num = int(input())

a = num // 100
b = num % 100 // 10
c = num % 100 % 10

if a > b > c:
    maxa, maxb, maxc = a, b, c
elif b > c > a:
    maxa, maxb, maxc = b, c, a
elif c > a > b:
    maxa, maxb, maxc = c, a, b
elif b > a > c:
    maxa, maxb, maxc = b, a, c
elif c > b > a:
    maxa, maxb, maxc = c, b, a
elif a > c > b:
    maxa, maxb, maxc = a, c, b

if maxa + maxc == maxb * 2:
    print('YES')
else:
    print('NO')
```

**Условия:**

1. Программа должна запрашивать у пользователя длины трех сторон треугольника (a, b, c).
2. Программа должна определить самую большую строну треугольника.
3. По теореме Пифагора нужно сравнить большую сторону с двумя оставшимися, и сделать вывод о типе треугольника.

- Если треугольник прямоугольный, то вывести сообщение "Треугольник прямоугольный"
- Если треугольник тупоугольный, то вывести сообщение "Треугольник тупоугольный"
- Если треугольник остроугольный, то вывести сообщение "Треугольник остроугольный"

**Примечание:**

Проверять на возможность построить треугольник из заданных отрезков не нужно

```python
a = int(input())
b = int(input())
c = int(input()) 

ma = max(a, b, c)
mb = min(a, b, c)
mc = a + b + c - ma - mb

if ma ** 2 == mb ** 2 + mc ** 2:
    print('Треугольник прямоугольный')
if ma ** 2 > mb ** 2 + mc ** 2:
    print('Треугольник тупоугольный') 
if ma ** 2 < mb ** 2 + mc ** 2:
    print('Треугольник остроугольный') 
```

**Задача:** Напишите программу, которая решает квадратное уравнение вида ax² + bx + c = 0. Программа должна принимать на вход три вещественных коэффициента (a, b, c) и выводить на экран корни уравнения в порядке возрастания, если они существуют.

**Условия:**

1. Программа должна обрабатывать все возможные случаи:
    - Нет решений: Если [дискриминант](https://www.kp.ru/edu/shkola/diskriminant/) меньше нуля, вывести "_Нет решения_".
    - Один корень: Если дискриминант равен нулю, вывести единственный корень с точностью до сотых.
    - Два корня: Если дискриминант больше нуля, вывести два корня в порядке возрастания с точностью до сотых.
    - Бесконечное число решений: Если a и b равны нулю, а c также равно нулю, вывести "_Бесконечное число решений_".
    
2. Вывод корней должен быть с точностью до двух знаков после запятой.

```python
a = float(input())
b = float(input())
c = float(input())

D = (b**2) - (4 * a * c)

if D > 0:
    x1 = (-1 * b + (D**0.5)) / (2 * a)
    x2 = (-1 * b - (D**0.5)) / (2 * a)
    if x1 > x2:
        print(round(x2, 2), round(x1, 2))
    else:
        print(round(x1, 2), round(x2, 2))
elif D == 0:
    x1 = -b / (2 * a)
    print(round(x1, 2))
else:
    x1 = None
    x2 = None
    print("Нет решения")
```
