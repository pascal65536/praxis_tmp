# Задача 50. Калькулятор

Эмуляция HTTP-обработчика `/calc`: по query-параметрам `a`, `b`, `op`
вычислить результат арифметической операции и вернуть ответ.

## Задание

Реализуйте в файле `student.py` функцию:

```python
def solve(a, b, op):
    ...
```

### Параметры

- `a` — первый операнд (строка из URL, может быть числом);
- `b` — второй операнд (строка из URL);
- `op` — операция (строка):
  - `"add"` — сложение: `a + b`;
  - `"mult"` — умножение: `a * b`;
  - `"diff"` — разность: `a - b`;
  - `"sub"` — **деление**: `a / b` (название историческое, см. условие).

### Возвращаемое значение

Словарь:

- при успехе — `{"result": <число>}`;
- при неизвестной операции — `{"error": "unknown operation"}`;
- при делении на ноль — `{"error": "division by zero"}`;
- при нечисловых `a`/`b` — `{"error": "invalid operands"}`.

### Пример

```
GET /calc?a=10&b=12&op=add   →  {"result": 22}
GET /calc?a=10&b=2&op=sub    →  {"result": 5.0}
```

## Проверяющая система

Каждый тест в `check.json` имеет структуру:

```json
{
    "id": 1,
    "description": "add: 10 + 12",
    "setup": "i1.py",
    "expected_file": "o1.py"
}
```

- `setup` — файл с вызовом `solve(...)`, кладёт результат в `ret`;
- `expected_file` — эталонное значение `ret`.

Инструкция по запуску — в `README.md`.
