# Калькулятор без фласка

## Что нужно сделать

Реализовать в файле `student.py` функцию `solve(a, b, op)`, эмулирующую
обработчик `/calc`.

## Состав файлов

| Файл             | Назначение                                                   |
| ---------------- | ------------------------------------------------------------ |
| `student.py`     | Ваше решение (единственный файл, который вы меняете)         |
| `check.py`       | Скрипт проверки (менять нельзя)                              |
| `check.json`     | Список тестов                                               |
| `i1.py`…`i10.py` | Вызов `solve(...)` для каждого теста                         |
| `o1.py`…`o10.py` | Эталонные значения `ret`                                     |
| `teacher.py`     | Эталонное решение (для справки)                              |

## Сигнатура функции

```python
def solve(a, b, op):
    """a, b — операнды (строки из URL); op — операция."""
```

### Операции

| `op`     | Действие        | Пример                     |
| -------- | --------------- | -------------------------- |
| `"add"`  | `a + b`         | `solve("10", "12", "add")` → `{"result": 22}` |
| `"mult"` | `a * b`         | `solve("3", "4", "mult")` → `{"result": 12}` |
| `"diff"` | `a - b`         | `solve("10", "3", "diff")` → `{"result": 7}` |
| `"sub"`  | `a / b` (деление)| `solve("10", "2", "sub")` → `{"result": 5.0}` |

### Формат ответа

- `{"result": <число>}` — при успехе;
- `{"error": "unknown operation"}` — если `op` не из списка;
- `{"error": "division by zero"}` — если `op == "sub"` и `b == 0`;
- `{"error": "invalid operands"}` — если `a`/`b` не приводятся к числу.

Если операнды — целые числа (`"10"`, `"-3"`), результат для `add`/`mult`/`diff`
должен быть `int`; для `sub` — `float`. Если хотя бы один операнд дробный —
результат `float`.

## Как запустить проверку

1. Сохраните все файлы в одной папке.
2. Напишите решение в `student.py`.
3. Выполните в терминале:

   ```bash
   python3 check.py
   ```

4. Итог — в конце вывода.

## Формат `check.json`

```json
{
    "tests": [
        {"id": 1, "description": "...", "setup": "i1.py", "expected_file": "o1.py"}
    ]
}
```

- `setup` — выполняется после `student.py`, должен определить `ret`;
- `expected_file` — эталон `ret` (Python- или JSON-литерал).

`check.json` не изменяйте.

## Как устроен один тест

1. `check.py` читает `student.py`.
2. Создаётся чистое пространство имён, выполняется `student.py`.
3. Выполняется `setup`-файл, например `i1.py`:

   ```python
   ret = solve(a="10", b="12", op="add")
   ```

4. Из `o1.py` загружается эталон, например:

   ```python
   {"result": 22}
   ```

5. Сравнение через `diff` (float — с допуском `1e-9`).

## Частые ошибки

| Симптом                                              | Причина                                              |
| ---------------------------------------------------- | ---------------------------------------------------- |
| `Переменная 'ret' не была создана`                   | `solve` бросила исключение                          |
| `ret['result']: ожидалось 22, получено '22'`         | Не выполнен `int(...)`/`float(...)`                 |
| `ret['result']: ожидалось 5.0, получено 5`           | Деление вернуло `int` (не должно)                   |
| `ret: ключи не совпадают ... ['error']`              | Ошибка не обработана (брошено исключение)           |
| `деление на ноль`                                    | Не проверено `b == 0` перед `a / b`                 |
| `операция "mult" не работает`                        | Перепутаны `op` (например, `"mul"`)                 |
