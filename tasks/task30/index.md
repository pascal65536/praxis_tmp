# Задача 30. Средний балл студента

Дан список имён студентов и соответствующие им списки оценок. Требуется вычислить
средний балл каждого студента. Дополнительно нужно уметь находить студента с
максимальным средним баллом по списку словарей.

## Задание

Реализуйте в файле `student.py` две функции:

```python
def calc(names, grades):
    ...


def calc_user_dct(users):
    ...
```

### `calc(names, grades)`

- `names` — список строк (имена студентов);
- `grades` — список списков чисел (оценки каждого студента, порядок соответствует `names`).

Функция возвращает список словарей вида `{имя: средний_балл}` — по одному словарю
на студента, в том же порядке, что и во входных данных.

Средний балл округляется до двух знаков после запятой (`round(avg, 2)`).

Если длины `names` и `grades` не совпадают, лишние элементы более длинного списка
игнорируются (поведение `zip`).

### `calc_user_dct(users)`

- `users` — список словарей вида
  `{"full_name": str, "grades": list[int], "missed_classes": int}`.

Функция возвращает **один** словарь — копию словаря студента с наибольшим средним
баллом, дополненную ключом `"avg"` (средний балл, число с плавающей точкой).

Если список пуст — вернуть пустой словарь `{}`. Исходные словари не мутируются.

## Примеры

### `calc`

| `names`                              | `grades`                          | Результат |
| ------------------------------------ | --------------------------------- | --------- |
| `["Анна", "Иван"]`                   | `[[4, 5], [3, 3, 3]]`             | `[{"Анна": 4.5}, {"Иван": 3.0}]` |
| `["A", "B"]`                         | `[[5], [4, 4]]`                   | `[{"A": 5.0}, {"B": 4.0}]` |
| `[]`                                 | `[]`                              | `[]` |
| `["X"]`                              | `[[5, 5, 4]]`                     | `[{"X": 4.67}]` |

### `calc_user_dct`

Вход:

```python
[
    {"full_name": "John Smith", "grades": [5, 4, 4, 5, 3], "missed_classes": 2},
    {"full_name": "Emily Johnson", "grades": [4, 5, 5, 4, 5], "missed_classes": 0},
    {"full_name": "Michael Brown", "grades": [3, 3, 4, 3, 3], "missed_classes": 5},
]
```

Результат:

```python
{"full_name": "Emily Johnson", "grades": [4, 5, 5, 4, 5], "missed_classes": 0, "avg": 4.6}
```

Пустой список на входе → `{}`.

## Проверяющая система

Проверяющая система использует файл `check.json`. Каждый тест имеет следующую структуру:

```json
{
    "id": 1,
    "description": "Тест calc: базовый контрольный набор из 5 студентов",
    "setup": "i1.py",
    "expected_file": "o1.py"
}
```

- `setup` — файл с входными данными и вызовом функции; после его выполнения в
  пространстве имён должна появиться переменная `ret`;
- `expected_file` — файл с ожидаемым значением `ret` (Python- или JSON-литерал).

Для каждого теста система:

1. внедряет функции из `student.py` в чистое пространство имён;
2. выполняет `setup`-файл;
3. читает ожидаемое значение из `expected_file`;
4. сравнивает `ret` с эталоном (числа с плавающей точкой — с допуском `1e-9`).

Инструкция по запуску находится в файле `README.md`.
