# Средний балл студента — инструкция по проверке

## Что нужно сделать

Реализовать в файле `student.py` две функции:

- `calc(names, grades)` — список словарей `{имя: средний_балл}`;
- `calc_user_dct(users)` — словарь студента с максимальным средним баллом,
  дополненный ключом `"avg"`.

## Состав файлов

В одной папке должны находиться:

| Файл         | Назначение                                                       |
| ------------ | ---------------------------------------------------------------- |
| `student.py` | Ваше решение (единственный файл, который вы меняете)             |
| `check.py`   | Скрипт проверки (менять нельзя)                                  |
| `check.json` | Список тестов: `setup`-файлы и `expected_file`-файлы             |
| `i1.py`…`i15.py` | Входные данные и вызов функции для каждого теста            |
| `o1.py`…`o15.py` | Эталонные значения `ret` для каждого теста                  |

## Сигнатуры функций

```python
def calc(names, grades):
    """Список словарей {имя: средний_балл}, округление до 2 знаков."""


def calc_user_dct(users):
    """Словарь студента с максимальным средним + ключ 'avg'. Пустой список → {}."""
```

### `calc`

- `names: list[str]` — имена студентов;
- `grades: list[list[int]]` — оценки, порядок соответствует `names`.

Возвращает `list[dict[str, float]]` — по одному словарю `{имя: средний}` на студента,
в исходном порядке. Средний балл округляется до двух знаков после запятой.

Если длины `names` и `grades` не совпадают — лишние элементы более длинного списка
игнорируются (поведение `zip`).

Пример:

```python
>>> calc(["Анна", "Иван"], [[4, 5], [3, 3, 3]])
[{"Анна": 4.5}, {"Иван": 3.0}]
```

### `calc_user_dct`

- `users: list[dict]` — список словарей вида
  `{"full_name": str, "grades": list[int], "missed_classes": int}`.

Возвращает `dict` — копию словаря студента с наибольшим средним баллом, с добавленным
ключом `"avg"`. Исходные словари не мутируются. Пустой список → `{}`.

Пример:

```python
>>> users = [
...     {"full_name": "John Smith", "grades": [5, 4, 4, 5, 3], "missed_classes": 2},
...     {"full_name": "Emily Johnson", "grades": [4, 5, 5, 4, 5], "missed_classes": 0},
...     {"full_name": "Michael Brown", "grades": [3, 3, 4, 3, 3], "missed_classes": 5},
... ]
>>> calc_user_dct(users)
{"full_name": "Emily Johnson", "grades": [4, 5, 5, 4, 5], "missed_classes": 0, "avg": 4.6}
```

## Как запустить проверку

1. Сохраните все файлы в одной папке.
2. Напишите решение в `student.py`. Не изменяйте имена функций и их сигнатуры.
3. Откройте терминал в папке с файлами и выполните:

   ```bash
   python3 check.py
   ```

   Если `python3` недоступен:

   ```bash
   python check.py
   ```

4. Дождитесь завершения проверки.

## Что вы увидите на экране

- для каждого теста — строку `PASS` или `FAIL`;
- для непройденных тестов — причину расхождения (какой ключ, индекс или значение
  не совпали);
- в конце — итог: сколько тестов пройдено из общего числа.

Пример:

```
✅ Тест 1: PASS
❌ Тест 2: FAIL
   Причина: ret[0]['Единственный']: ожидалось 4.67, получено 4.666666666666667
...
==================================================
Итог: пройдено 13 из 15 тестов.
```

## Формат `check.json`

```json
{
    "tests": [
        {
            "id": 1,
            "description": "Тест calc: базовый контрольный набор из 5 студентов",
            "setup": "i1.py",
            "expected_file": "o1.py"
        }
    ]
}
```

- `id` — номер теста;
- `description` — человекочитаемое описание (в сравнении не участвует);
- `setup` — файл, который выполняется после `student.py`; должен определить `ret`;
- `expected_file` — файл с эталонным значением `ret`.

`check.json` **не изменяйте** — проверяющая система использует именно его.

## Как устроен один тест

1. `check.py` читает код `student.py`.
2. Для каждого теста создаётся **чистое** пространство имён.
3. В него выполняется `student.py` (определяются `calc` и `calc_user_dct`).
4. Выполняется `setup`-файл, например `i1.py`:

   ```python
   name = ["Анна", "Борис", "Глеб", "Вадим", "Иван"]
   grade = [[2, 3, 4, 5], [2, 3, 5, 5], [2, 4, 4, 5], [5, 3, 4, 5], [3, 3, 3, 3]]
   ret = calc(name, grade)
   ```

5. Из `expected_file` (например, `o1.py`) загружается эталон:

   ```python
   [
       {"Анна": 3.5},
       {"Борис": 3.75},
       {"Глеб": 3.75},
       {"Вадим": 4.25},
       {"Иван": 3.0},
   ]
   ```

6. `ret` сравнивается с эталоном через `diff`:
   - `dict` — сравниваются наборы ключей и значения по ключам;
   - `list` — сравниваются длины и поэлементно;
   - `float` — с допуском `rel_tol=1e-9`, `abs_tol=1e-9`;
   - остальное — через `==`.

## Частые ошибки

| Симптом                                            | Причина                                                         |
| -------------------------------------------------- | --------------------------------------------------------------- |
| `Тест N: FAIL. Переменная 'ret' не была создана`   | `setup`-файл не смог выполниться (например, функция бросила исключение) |
| `Причина: ret[0]: ключи не совпадают`              | Функция вернула не тот набор ключей                             |
| `Причина: ret[0]: длина списка ... вместо ...`     | Неверное число студентов в результате                           |
| `Причина: ret[0][...]: ожидалось 4.5, получено 4.0`| Неверная формула среднего                                       |
| `Причина: ... ожидалось 4.67, получено 4.6666...`  | Нет округления `round(avg, 2)` в `calc`                         |
| `TypeError: unsupported operand ...`               | В `grades` попало не число или пустой список                    |
| `KeyError: 'grades'`                               | В `calc_user_dct` неверно читается поле словаря                 |
