## Задача 2

Написать программу, которая запрашивает у пользователя ввод пароля и проверяет его на соответствие требованиям безопасности.

Пароль должен содержать не менее 8 символов, цифры, специальные символы и буквы как в нижнем, так и в верхнем регистре.

Если пароль не соответствует этим требованиям, то программа запрашивает новый пароль до тех пор, пока не будет введен правильный пароль. После этого программа выводит сообщение с правильным паролем.

PS. Пароли также не могут содержать слова из словаря, но в данной работе мы это игнорируем.

### Примеры

**Пример 1**

Ввод:
```
wef
wefeqrg
34tFLK
sfLK!#
asfLGEKJH890*)(
```

Вывод:
```
asfLGEKJH890*)(
```

**Пример 2**

Ввод:
```
123
abcdefg
Abcdef1
Abcdef1!
```

Вывод:
```
Abcdef1!
```

**Пример 3**

Ввод:
```
password
Password
Password1
Password1!
```

Вывод:
```
Password1!
```

**Пример 4**

Ввод:
```
qwerty
qwerty1
Qwerty1
Qwerty1!
```

Вывод:
```
Qwerty1!
```
