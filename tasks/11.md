## Задача: Классы Rectangle и Square

Создайте два класса, ***Rectangle*** и ***Square***, которые представляют геометрические фигуры: прямоугольник и квадрат соответственно. Каждый класс должен самостоятельно реализовывать необходимые методы и атрибуты.

Класс *Rectangle* должен содержать два атрибута — *width* и *height*. Также класс должен содержать следующие методы:

1. конструктор *__init__(self, width, height)*, принимающий *width* и *height* в качестве параметров и инициализирующий соответствующие атрибуты.
2. *area(self)* — метод, который возвращает площадь фигуры.
3. *perimeter(self)* — метод, который возвращает периметр фигуры.
4. *__str__(self) и __repr__(self)* — методы, которые возвращают строковое представление объекта.

Класс *Square* должен содержать один атрибут — *side_length*. Также класс должен содержать методы, аналогичные классу *Rectangle*.

### Примеры

**Пример 1**

Ввод (код):
```
square = Square(4)
print(square)
rectangle = Rectangle(4, 6)
print(rectangle)
```

Вывод:
```
Квадрат со стороной 4
Прямоугольник со сторонами 4 и 6
```

**Пример 2**

Ввод (код):
```
print(Square(5).perimeter())
print(Square(5).area())
rectangle = Rectangle(7, 3)
print(rectangle.perimeter())
print(rectangle.area())
```

Вывод:
```
20
25
20
21
```

**Пример 3**

Ввод (код):
```
object_lst = [Rectangle(7, 3), Square(5), Rectangle(2, 8), Square(13)]
for obj in object_lst:
    print(obj)
```

Вывод:
```
Прямоугольник со сторонами 7 и 3
Квадрат со стороной 5
Прямоугольник со сторонами 2 и 8
Квадрат со стороной 13
```

**Пример 4**

Ввод (код):
```
object_lst = [Rectangle(7, 3), Square(5), Rectangle(2, 8), Square(13)]
print(sum([z.area() for z in object_lst]))
```

Вывод:
```
231
```

**Пример 5**

Ввод (код):
```
object_lst = [Rectangle(11, 13), Square(15), Rectangle(12, 82), Square(135)]
print(max([z.perimeter() for z in object_lst]))
```

Вывод:
```
540
```
